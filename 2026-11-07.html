cloudflare/security-audit-skill

JavaScriptAgent 安全审计漏洞发现Cloudflare 官方
今日新增 2,548 星，总星数 63,965，Fork 4,145；日榜第一，月增 38,004 星

Cloudflare 官方出品的编码 Agent 安全审计技能，目标是把 Agent 变成一名“安全审计员”。它按六个阶段组织一次审计：侦察（画架构、信任边界与输入面，记入覆盖台账）、覆盖驱动的猎取（隔离的猎手 Agent 按台账分工找漏洞）、候选验证（每个疑似漏洞交给一个全新的验证 Agent 尝试证伪）、结构化输出（结论只分 confirmed、needs_validation、rejected 三档，写入 findings.json 并过 JSON Schema 校验）、独立复核（再派新人核对最终报告里的每一条源码引用）、中立报告（从已验证记录派生报告）。设计原则写得很硬：只有确立的边界失效才算确认；查的人和验的人不能是同一个 Agent；严重度看影响而非偏离清单；单层缺失不算漏洞；多跑几遍覆盖率会上升（实测单次只找到重复跑总数的约一半）。这个技能正是 Cloudflare 漏洞发现流水线（harness）的单仓库起点，2026 年 6 月 18 日建仓，至今只有 14 次提交，MIT 开源。

💡 点评：代码生成技能遍地之后，安全审计是 Agent 技能最自然的下一个专业分工——能写代码的 Agent 迟早要为自己写的代码负责。

mattpocock/skills

ShellAgent Skills工程方法效率工具
今日新增 2,070 星，总星数 316,699，Fork 26,493；日榜第二，连续三日位列日榜前三

TypeScript 教育者 Matt Pocock 把自己每天真正在用的 Agent 技能直接开源，定位是“给真正做工程的人，不是给 vibe coding 的”。它针对编码 Agent 的四个典型翻车点各给一套打法：对不上需求用 /grill-me、/grill-with-docs 先“拷问”对齐并沉淀领域术语表；话太多用共享语言（GLOSSARY.md）与 ADR 收敛；代码跑不通靠 /tdd 红绿重构循环与 /diagnosing-bugs 分阶段诊断；越写越烂用 /improve-codebase-architecture 定期扫描深模块机会。技能分用户调用与模型自动调用两类，覆盖 Claude Code、Codex、Copilot、Gemini CLI 等多家 Agent，安装后每仓库跑一次 /setup-matt-pocock-skills 即可。仓库 2026 年 2 月建仓，已有 553 次提交，MIT 开源。

💡 点评：Skills 热潮里它是最“反潮流”的一个——不追新功能，只把几十年工程基本功压成可复用的套路；总星数逼近 32 万，说明开发者要的不是更聪明的 Agent，而是更靠谱的工作方式。

NVIDIA/auto-ontology

PythonAgent 语义层知识图谱NL-to-SQL
今日新增 2,015 星，总星数 9,002，Fork 724；日榜第三，连续第三天站上日榜前三

NVIDIA 官方出品的语义层框架：从企业数据库元数据自动生成“本体”——业务术语、指标口径、表间关系构成的知识图谱，再经 MCP、CLI 或 API 供 Agent 调用。核心卖点是“可验证的问答”：Agent 回答业务问题时，先把“收入”“客户”这类词解析到本体中经人工认证的定义上，再生成 SQL，答案附带 SQL 与推导步骤；答不出来的问题会明确说数据不支持，而不是编一个数。推理默认走 NVIDIA NIM 模型。11 月 5 日首登榜首（单日涨 2,050 星），11 月 6 日再涨 2,679 星蝉联榜首，今天以 2,015 星守住前三，三天合计吸星约 6,700 颗。

💡 点评：Agent 接入企业数据的最大拦路虎是口径不一致；NVIDIA 把语义层做成开源基础设施，等于给所有 Agent 发了一本“企业词典”。

Google 在 Cloud Next 2026 上发布的官方 Agent Skills 仓库：把 Google Cloud 与 Workspace 的领域知识打包成 Markdown 技能文件，供 AI 编码 Agent 按需加载。首批 13 个技能，覆盖 BigQuery、GKE、Cloud Run、Firebase、Gemini API、AlloyDB、Cloud SQL 七个产品，外加安全、可靠性、成本优化三条架构支柱与上手配方；每条技能入库前要过内部 CI/CD 验证，优先引用远程 MCP 工具。安装只需 npx skills install github.com/google/skills，兼容所有支持 Skills 规范的 Agent。发布时首波反响即超 1.5 万星，之后稳步爬到 2.2 万；同一赛道的 Anthropic 官方技能库本周增 3,159 星、总星数已达 188,169。

💡 点评：Anthropic、Google、NVIDIA 纷纷亲自下场写“工作手册”，说明 Skills 之争已从社区自发变成平台标配——谁定义技能，谁就定义 Agent 怎么干活。

pingdotgg/t3code

TypeScriptAgent 操控台多 Agent 管理移动端
本周新增 16,782 星，总星数 49,793，Fork 9,746；本周最大增量，月增 23,406 星

T3 Code 是一个“Agent 操控台”（agent harness control surface）：用手机 App、网页或 Electron 桌面端，统一操控本机上跑着的多个编码 Agent——Claude Code、Codex、Cursor、Grok Build、OpenCode、Google Antigravity、fx，用的是你自己的订阅。作者是知名开发者 Theo（pingdotgg），立项动机写在 README 里：受 Codex 桌面端、Conductor、Claude Desktop 等启发，但没有一个达到他们的标准，于是自己做了一个“高性能、可远程、真正开源”的。仓库 2026 年 2 月建仓，已有 9,657 次提交、788 个 Release，更新极其活跃；安装一条命令 curl -fsSL https://t3.codes/install.sh | sh，MIT 开源。

💡 点评：Agent 从一个变成一群之后，缺的不是更强的模型，而是一个能同时管住它们的“控制台”——手机上随时看 Agent 干活，是这波热度的直接卖点。
