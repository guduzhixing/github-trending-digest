cloudflare/security-audit-skill

安全审计Agent Skill日榜第1
日新增 +2,012｜月新增 +16,694｜总星 36,434
💡 Cloudflare 官方（9 月 14 日，MIT 许可）发布的编码 agent 安全审计 skill，回应"agent 写代码、谁来审代码"的痛点。它不是软件而是 markdown 指令集加两个零依赖 JS 校验器：把 agent 变成"审计负责人"，按六阶段（侦察→覆盖率驱动狩猎→候选验证→结构化输出→独立复核→报告）跑完整审计。技术亮点有三：找 bug 的 hunter 和负责证伪的 verifier 严格分离；每个结论按 confirmed / needs_validation / rejected 分档，沙盒不足时自动降级；结论必须附完整源码溯源，输出机器可读 findings.json。Cloudflare 称它源自自家内部漏洞挖掘平台，并自述在 25 个开源项目中找出 493 个问题（官方数据，第三方未独立核实）。正在搭 agent 代码流水线的团队值得试用。

stablyai/orca

Agent 编排日榜第3
日新增 +1,541｜周新增 +8,705｜总星 101,225
💡 开源（MIT）桌面应用：不是 agent 本身，而是 agent 的"舰队指挥台"。核心玩法是把同一个提示扇出给多个 coding agent（Claude Code、Codex、OpenCode、Grok、Cursor、Copilot、Pi 等），每个 agent 在独立 git worktree 里并行干活，做完后并排对比、只合并优胜者。解决三个现实问题：agent 单次输出不稳定、串行重试烧时间、多家 agent 订阅难管理。还附带手机伴侣 App（推送通知加远程跟进）、SSH 远端 worktree、Claude/Codex 用量与速率限制追踪，支持 macOS/Windows/Linux 和 iOS/Android。作者是 YC 系的 Stably AI（具体 batch 未核实）。适合每天跟多个 agent 打交道、受够了手动对比 diff 的开发者。

Agent 哲学极简主义日榜第5
