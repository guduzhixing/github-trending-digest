pingdotgg/t3code

TypeScriptAgent 控制台桌面 / 网页 / 移动端多 Agent 统一调度
今日新增 3,094 星，总星数 37,953，Fork 8,913；日榜第四，周榜新增 6,926 星，月榜新增 12,629 星

今日单日涨幅最大的项目，也是一张“Agent 遥控器”：它本身不是模型，而是一个 Agent 操控台，让本机上已经装好的 Claude Code、Codex、Cursor、Grok Build、OpenCode、Google Antigravity 等 Agent 共用一套桌面、网页与移动端界面。最近发布的 v0.1.0 稳定了 Orchestrator V2，Agent 可以跨供应商委派子任务、通过 MCP 管理会话线程，并支持 Git worktree 与一键提交 PR。它火的原因很直白：人手里的 Agent 越来越多，缺的不是又一个助手，而是一个能把它们统一管起来的操作面。

💡 点评：同时在用多个编码 Agent 的开发者值得一试；但项目自认仍处于非常早期阶段，上车前要按“会遇到 bug”的预期来评估。

thedotmack/claude-mem

TypeScriptAgent 记忆会话上下文跨工具
今日新增 1,526 星，总星数 109,238，Fork 9,564；日榜第一，周榜新增 5,852 星，月榜新增 14,011 星

继续霸榜的 Agent 长期记忆层：把每次会话中 Agent 的所作所为记录下来，用 AI 压缩成结构化记忆，在未来会话中按需注入，支持 Claude Code、Codex、Gemini、Copilot、OpenCode 等多种工具。它在日、周、月三榜同时居前排，总星数突破十万后仍在快速上涨，说明它已从尝鲜工具变成不少人工作流里的默认配置。当 Agent 开始承担多天、跨项目的连续工作时，上下文窗口再大也装不下全部历史，外部记忆就成了刚需。

💡 点评：记忆正在成为 Agent 基础设施的标配层；上车前先想清楚两道关：记什么、不记什么，以及旧记忆出错时如何纠正。

lightpanda-io/browser

Zig无头浏览器AI 自动化CDP / MCP
今日新增 825 星，总星数 40,106，Fork 1,960；日榜第二

为 AI 与自动化从零写起的无头浏览器：不用 Chromium 分支、不用 WebKit 补丁，Zig 编写，跳过图形渲染，只保留 DOM、JavaScript 执行（V8）与自动化真正需要的部分。它兼容 Chrome DevTools 协议，现有 Puppeteer、Playwright 脚本改个接入点就能试用，还自带 MCP 服务器与“用自然语言描述任务”的 Agent 模式。项目自称比无头 Chrome 省约 16 倍内存、快约 9 倍——这是项目方自己的基准数据，未经独立复现，引用时要带上这个限定。它在 10 月刚发布 1.0，Agent 大规模上网的成本问题正好撞上它的卖点。

💡 点评：做大规模抓取、表单自动化或浏览器 Agent 的团队值得做一次对照测试；但它没有渲染引擎，不适合视觉验收类场景，复杂页面的兼容性仍需实测。

shiyu-coder/Kronos

Python金融基础模型K 线预测量化研究
今日新增 630 星，总星数 45,364，Fork 7,499；日榜第三

把 K 线当成“语言”来建模的基础模型：专用分词器把连续的 OHLCV（开高低收量）行情离散成 token 序列，再用自回归 Transformer 在来自 45 家全球交易所、超过 120 亿条 K 线的语料上预训练，论文已被 AAAI 2026 接收。用法上既可以直接加载预训练模型预测未来一段 K 线，也能用自己的行情数据微调。它今天上榜的背景，是“专用基础模型”这条路线正在从通用大模型里分化出来：与其让通用模型现学金融，不如直接给市场语言训一个原生模型。

💡 点评：量化研究者与金融数据开发者最值得关注；但要按研究工具定位它——作者与第三方评测都提醒，原始预测信号离可交易策略还有距离，不能直接当成赚钱机器。

anomalyco/hex

Rust本地语音听写跨平台隐私优先
今日新增 1,179 星，总星数 3,252，Fork 189；日榜第十二

按住快捷键、说话、松开，文字就粘贴到当前应用——来自 OpenCode 背后团队 Anomaly 的本地语音听写工具，Rust 编写，覆盖 Mac、Windows 与 Linux。首次运行下载本地语音模型后，日常听写不再经过云端，录音默认不保存，Mac 版历史记录默认只保留七天且不含音频。单日新增星数已接近其总星数的三分之一，说明它正处在刚被发现的爬坡期，10 月 31 日刚宣布稳定版可用也是直接导火索。

💡 点评：对云端语音转写有隐私顾虑、又想用说的代替打字的人可以先装来试；但要注意自定义模型支持与部分平台的快捷键问题仍是社区反馈中的短板。
