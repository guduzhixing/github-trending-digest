ifixai-ai/iFixAi

给 AI agent 做"独立体检"的审计引擎，一句话 slogan 就是"你的 agent 真的在按要求干活吗？120 秒内给答案"。用法极简单：pip install "ifixai[openai]"，可以人跑、也可以 agent 自己跑自己（self-audit）。开源版含 60 项检查（inspection），按 B01–B32 等类别映射到对齐、安全、合规多维度；付费版 iFixAi Pro 扩展到 400 项检查，并附运营保障 + 合规两份报告和 "Audited by iFixAi" 徽章。方法论有点意思：审计不止看漏洞和是否完成任务，还把 AI 红队、治理、运维保障、哲学/伦理/社会学视角拼在一起，评估 agent 在业务语境下的错位（misalignment）。项目 2026 年 4 月 27 日创建，在 GitTrend 日榜已连续露面 113 天、10 月 1 日冲到第 5，持久力惊人。注意它默认发伪匿名遥测（可关：--no-telemetry 或环境变量），审计结论对敏感链路请自行验证。

💡 点评：agent 遍地跑，"谁审计 agent" 是刚需生态位，开源+付费审计服务的打法和代码审计行业的商业化路径很像。把 agent 交到生产环境前，值得先跑一遍。

"渗透测试 AGI"——全自主的多 agent 渗透测试系统：你只管给目标，它自己规划、自己执行、自己出报告。架构是 supervisor + worker：主管定策略选工具，工人跑扫描/利用/写报告；所有动作都在隔离的 Docker 沙箱里，20+ 专业工具（Nmap、Metasploit、sqlmap、Nuclei、Burp 等）自动编排。记忆系统是亮点：Graphiti 知识图谱（Neo4j）+ 向量记忆存下每次测试的经验和成功打法，长测试链用链式摘要防止上下文爆掉；内置浏览器爬取目标情报，Tavily/Perplexity 等搜索 API 补实时数据；报告带 PoC 和修复建议，存 Postgres + pgvector 可语义检索，还有 Grafana 看板。模型端支持 OpenAI、Anthropic、Gemini、Bedrock 和 Ollama 本地模型，Web UI 一键部署。VXControl 2025 年初开源。双用途工具属性极强，仅限授权测试场景使用。

💡 点评：安全攻防的 agent 化和昨天 rea 带起的逆向 agent 化是同一波浪潮。红队自动化、SRC 常态化评估的团队可以研究架构，合规边界自行把握。

heygen-com/hyperframes

周榜第 4 · 月榜第 6TypeScriptApache-2.0
本周 +5,123 星 · 本月 +13,722 星 · 总 63,688 星

HeyGen 开源的"给 agent 的视频渲染引擎"，口号三句话：Write HTML. Render video. Built for agents。核心洞察是：让 agent 写标准 HTML（加 data-* 时间轴属性），而不是 JSON 配置或专有 DSL——因为模型真正"理解" CSS 布局，能推理画面长什么样（visual grounding），这正是 agent 做视频的最大能力缺口。管线是 headless Chrome 逐帧确定性抓取 + FFmpeg 编码，同一份输入每次渲染结果完全一致，可进 CI、可版本管理；GSAP、Lottie、Three.js、WebGL 着色器都能跑，"浏览器能显示什么，它就能渲染什么"。配套很全：CLI、Studio 可视化编辑器、无头 SDK、MCP 连接器、150+ 预置动画块，渲染目标覆盖本机、AWS Lambda、GCP Cloud Run。2026 年 3 月首提交、4 月 17 日公开，两个月冲 3 万星；同年 7 月引擎被收进 HeyGen 付费产品 Video Agent，开源与商业并行。许可证无席位限制。

💡 点评：Remotion 的 agent 原生挑战者。需要"视频即代码"管线（批量生成营销视频、数据可视化短片）的团队可以直接试，deterministic render 是生产级管线的入场券。
