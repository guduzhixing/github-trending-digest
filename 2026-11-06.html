重点项目

NVIDIA/auto-ontology

PythonAgent 语义层知识图谱NL-to-SQL
今日新增 2,679 星，总星数 7,286，Fork 578；连续第二天日榜第一

NVIDIA 官方出品的语义层框架：从企业数据库元数据自动生成“本体”——业务术语、指标口径、表间关系构成的知识图谱，再经 MCP、CLI 或 API 供 Agent 调用。核心卖点是“可验证的问答”：Agent 回答业务问题时，先把“收入”“客户”这类词解析到本体中经人工认证的定义上，再生成 SQL，答案附带 SQL 与推导步骤；答不出来的问题会明确说数据不支持，而不是编一个数。推理默认走 NVIDIA NIM 模型。昨日首登榜首时单日涨 2,050 星，今天再涨 2,679 星、总星数从 4,938 冲到 7,286，增速不降反升。

💡 点评：Agent 接入企业数据的最大拦路虎是口径不一致；NVIDIA 把语义层做成开源基础设施，等于给所有 Agent 发了一本“企业词典”。

vercel-labs/agent-desktop

RustComputer Use桌面自动化无障碍树
今日新增 2,173 星，总星数 16,820，Fork 1,186；日榜第三

Vercel Labs 的开源 CLI（另有 C 库，Apache-2.0）：让编码 Agent 不靠截图操作原生桌面应用。它读操作系统的无障碍树（macOS AX API、Windows UI Automation、Linux AT-SPI），把每个可操作元素变成带编号的 JSON 节点；Agent 按编号点击、输入，再重新快照验证结果，全程不移动鼠标、不抢焦点（--headed 模式除外）。它本身不含模型，观察—行动—验证的循环留在 Agent 一侧；共 60 条命令，覆盖快照、点击、键盘、窗口、剪贴板等，另有 MCP 服务与官方 Skill 可装。作者测算的省 token 账很直观：只看一个区域的快照约 273 个 token，整窗则要 3,811 个。局限也写在明处：不发布无障碍树的界面它看不见，网页自动化仍要交给姊妹工具 agent-browser。

💡 点评：本周早些时候它已登顶过日榜；截图式 Computer Use 贵且不稳定，读结构树这条路一旦走通，Agent 才算真正长出了“手”。

D4Vinci/Scrapling

Python自适应爬虫反爬绕过MCP
今日新增 1,655 星，总星数 97,950，Fork 10,255；日榜第四

Python 自适应爬虫框架，核心只解决一个痛点：爬虫总在目标网站改版那天集体失效。它的解法是给抓过的元素存“指纹”（标签、文本、关键属性、父级结构），网站改版后用相似度算法重新定位同一数据，不用重写选择器。三档抓取器各司其职：普通 HTTP（浏览器 TLS 指纹伪装、HTTP/3）、StealthyFetcher（加固版 Chromium，应对 Cloudflare 验证）、DynamicFetcher（完整 Playwright，跑 JS 渲染页）；另有类 Scrapy 的 Spider 引擎与内置 MCP 服务，可供 AI 直接调用做数据提取。作者 Karim Shoair 几乎一人写了约 95% 的提交，BSD 协议开源。

💡 点评：总星数距 10 万只差一步；Agent 时代爬虫不再是脚本小活，而是 Agent 的“数据入口”——入口越稳，Agent 越敢接需要实时数据的任务。

google/skills

PythonAgent SkillsGoogle Cloud官方技能库
今日新增 211 星，总星数 22,361，Fork 1,891；日榜第九

Google 在 Cloud Next 2026 上发布的官方 Agent Skills 仓库：把 Google Cloud 与 Workspace 的领域知识打包成 Markdown 技能文件，供 AI 编码 Agent 按需加载。首批 13 个技能，覆盖 BigQuery、GKE、Cloud Run、Firebase、Gemini API、AlloyDB、Cloud SQL 七个产品，外加安全、可靠性、成本优化三条架构支柱与上手配方；每条技能入库前要过内部 CI/CD 验证，优先引用远程 MCP 工具。安装只需 npx skills install github.com/google/skills，兼容所有支持 Skills 规范的 Agent。发布时首波反响即超 1.5 万星，如今稳步爬到 2.2 万。

💡 点评：Anthropic 的官方技能库已近 19 万星，Google、NVIDIA 纷纷跟进——大厂亲自下场写“工作手册”，说明 Skills 之争已从社区自发变成平台标配。

HKUDS/DeepTutor

PythonAI 家教个性化学习RAG
本周新增 6,229 星，总星数 55,442，Fork 6,796；周榜第五

港大 HKUDS 课题组的开源 AI 学习工作台，定位是“终身个性化辅导”而非问答聊天机器人：聊天、提问、测验、研究、可视化、解题、精通路径、沉浸阅读、音频概览九种模式跑在同一能力运行时上，共享会话上下文与知识库。知识引擎可插拔（LlamaIndex、GraphRAG、LightRAG、WeKnora、腾讯 IMA、MarginNote、Kiwix、Obsidian 等），记忆分三层落盘（原始记录、要点摘要、跨面综合），可查看可编辑；另有 arXiv 论文说明设计。后端 Python、前端 Next.js 16，自托管部署，Apache-2.0 开源，10 月 28 日刚发 v1.7.0。10 月 29–30 日它曾两度登顶日榜，本周热度未减。

💡 点评：聊天机器人只负责“答”，DeepTutor 想负责“教会”——把练习、进度与个人知识库绑在一起，是 AI 教育从 Demo 走向产品的关键一步。
