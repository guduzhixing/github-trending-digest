重点项目

pbakaus/impeccable

RustAgent 技能设计评审反 AI 味
今日新增 2,300 星，总星数 97,042，Fork 5,714；周榜新增 11,323 星，月榜新增 24,624 星，三榜同时在前排

给编码 Agent 配一套设计词汇：用 polish、bolder 打磨页面，用 critique 做带评分的可用性评审、用 audit 查无障碍与性能，另有 62 条确定性规则的“AI 味”检测器，无需大模型、无需 API Key 即可扫描。它火的原因很直白：Agent 生成的页面越来越像——Inter 字体、紫蓝渐变、卡片套卡片，开发者受够了千篇一律的默认审美。项目同时提供 Claude Code、Cursor、Codex、Copilot 等二十余种工具的安装形态，等于把“品味”做成可复用的技能包。

💡 点评：这不是又一个 UI 组件库，而是把设计评审前置到 Agent 工作流里；做 AI 生成前端的团队值得先跑一遍它的检测器，再谈审美。

HKUDS/DeepTutor

PythonAI 家教多智能体RAG
今日新增 2,282 星，总星数 51,764，Fork 6,340；Python 日榜第一

主打“终身个性化家教”：把教材、笔记建成知识库，让多智能体围绕学习者做阅读、练习、测评与学习路径规划，刚在 10 月 28 日发布 v1.7.0，带来模块化安装、块笔记与可续传的索引检查点。它与通用聊天机器人拉开差距的地方在于学习闭环：不是答完一道题就结束，而是记录掌握程度、安排复习与下一步内容，适合把 AI 当长期学习伙伴而非一次性问答工具的人。

💡 点评：教育类 Agent 正在从“能讲题”走向“能管学习进程”，DeepTutor 的高频发版说明这条路线的迭代速度很快，适合自学者和做教育产品的开发者对照参考。

thedotmack/claude-mem

TypeScriptAgent 记忆会话上下文
今日新增 1,140 星，总星数 106,226，Fork 9,352；日榜第一，月榜新增 11,124 星

解决 Agent 最常见的失忆问题：把每次会话中 Agent 的所作所为记录下来，用 AI 压缩成结构化记忆，在未来会话中按需注入。它支持 Claude Code、Codex、Gemini、Copilot、OpenCode 等多种工具，定位是跨工具的“长期记忆层”。当 Agent 开始承担多天、跨项目的连续工作时，上下文窗口再大也装不下全部历史，外部记忆就成了刚需，这正是它总星数破十万的背景。

💡 点评：记忆正在成为 Agent 基础设施的标配层；与其让每个工具各自记，不如先看这种跨工具方案的取舍，留意隐私与记忆污染两道关。

CopilotKit/OpenBot

TypeScriptAI 同事AG-UI自托管
今日新增 706 星，总星数 8,779，Fork 1,107

开源的“AI 同事”平台：每个同事拥有一台自己的电脑——独立浏览器、独立文件、只被授予的工具；每一次操作都先决策、事后留痕，基于 AG-UI 协议接入 LangGraph、Mastra、CrewAI 等任意 Agent 框架。它的卖点不是更强的模型，而是可治理：数据落在自己的 PostgreSQL，模型自选，动作全部经过统一网关审批与审计。目前仍标注 Beta，官方也直言这是一个“模板而非成品”，需要自己部署改造。

💡 点评：当 Agent 从聊天框走向替你操作系统时，“能不能管住它”比“它有多聪明”更重要；OpenBot 把审计与边界做成一等公民，适合对数据主权敏感的团队评估。

Renhuai123/ziwei-doushu

TypeScript紫微斗数排盘引擎传统文化数字化
今日新增 1,126 星，总星数 11,195，Fork 2,233

开源的紫微斗数排盘引擎，基于倪海厦《天纪》体系，包含完整排盘算法、四化系统、格局知识库与古籍原文数据。它的走红说明开源社区的兴趣并不只在 AI 工具：把一套规则复杂、口传心授的传统推算体系做成可验证、可复用的代码，本身就是有价值的数字化工作。需要注意的是，排盘是命理计算工具，其推算结果不具备科学预测效力，适合当作文化与算法研究项目看待。

💡 点评：传统文化题材 + 扎实的知识库工程，是一条容易被低估的开源路线；对传统文化数字化感兴趣的开发者可以重点看它的数据组织方式。
