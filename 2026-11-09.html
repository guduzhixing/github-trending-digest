NVIDIA/auto-ontology

Python语义层NL-to-SQLAgent 推理
本周新增 9,327 星，总星数 10,373，Fork 837；周榜首位，本周新增占总星数九成

NVIDIA 开源的 Python 框架，给企业数据建一层“语义推理层”：从数据库元数据自动生成本体（术语、关系、SQL 属性），再由人认证，最后 Agent 通过 MCP、CLI 或 API 用它回答自然语言问题、生成 SQL。解决的核心痛点是 Agent 查数“快但不一定对”——各系统里指标口径不一致时，先统一定义再查数；答案附带 SQL 与推导步骤、可溯源，数据里答不了的问题会先说“没有”而不是编一个。技术栈为 FastAPI + LangChain 后端、Next.js 前端、Postgres + pgvector 存本体，推理默认走 NVIDIA NIM（Nemotron 系列模型），支持 Helm/K8s 与 Docker Compose 部署。仓库 2026 年 4 月建仓、1,367 次提交，Apache 2.0 开源。

💡 点评：Skills 管“会干活”、记忆层管“记得住”，auto-ontology 补的是“算得对”——Agent 从写代码走向查数、做分析时，口径统一的语义层是绕不过去的一环；NVIDIA 这次直接把自家 NIM 模型与开源框架绑在一起推。

pingdotgg/t3code

TypeScriptAgent 操控台多 Agent 管理远程开发
本周新增 15,379 星，总星数 52,481，Fork 10,014；本周全榜最大增量，月增 25,840 星

“Agent 操控台”：一个控制面统一管本机上的所有编码 Agent——Claude Code、Codex、Cursor、Grok Build、OpenCode、Google Antigravity、fx，用你自己的订阅，不经过中间代理。提供手机 App、Web App 与 Electron 桌面端，远程也能操控。仓库 2026 年 2 月建仓，至今 9,756 次提交、795 个 Release，MIT 开源。

💡 点评：Skills、记忆层之后，操控台成了 Agent 工具链的下一个争夺点——谁管得住一屋子 Agent，谁就管得住开发者的工作流；连续两周周增过万，说明这不是一日热度。

sherlock-project/sherlock

PythonOSINT用户名检索安全工具
今日新增 2,373 星，总星数 103,446，Fork 12,125；日榜第一，连续两天领跑且今日增量高于昨日

开源社区的老牌 OSINT 工具，解决的问题很具体：只知道一个用户名时，快速查出它在哪些社交网络注册过账号，拼出一幅公开账号版图。Python 写成，用法就是命令行里给一个用户名、等它逐站比对返回结果。适用场景是安全研究、招聘背调与记者核查一类的公开信息核验，使用时须遵守各平台规则与当地法律。

💡 点评：工具本身没有新功能，火的是需求——Agent 满世界替人办事之前，先要确认对面是谁；身份核查正从安全圈的手艺活变成 Agent 工作流的前置步骤。

ranxianglei/billion-context

TypeScript上下文压缩长会话Token 节省
今日新增 460 星，总星数 5,133，Fork 404；日榜第九，作者同时登上今日开发者榜第二

上下文压缩插件，解决长会话“上下文爆掉、账单爆掉”：坐在 Agent 与模型 API 之间，由模型自己决定何时、把哪段对话压成高保真摘要，可逆、可按需解压、可关键词检索；压缩后前缀缓存命中率仓库自述 95–97%。宣称 100K 上下文就够用、省 5 倍 token、单会话可跑月级、累计数十亿 token。支持 20 余种客户端（Pi、Claude、Codex、Gemini、Qwen、Antigravity 等），2026 年 8 月建仓，8,102 次提交、206 个 Release。仓库自述的 1,500 项第三方评测称 ContextBench 第一、LongMemEval-S 超最佳 RAG 16.6%，为自述数据、待独立复核。

💡 点评：claude-mem 管“跨会话记得住”，billion-context 管“单会话装得下”——记忆与压缩正在成为 Agent 长跑的两条腿；中国开发者在这一赛道的存在感值得留意。
