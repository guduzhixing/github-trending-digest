alibaba/open-code-review

代码评审确定性工程 × Agent阿里内部工具开源Apache-2.0
今日新增 215 星，总星数 50,606，Fork 3,762；日榜第一

阿里集团内部官方 AI 代码评审助手的开源版，过去两年服务数万名开发者、发现数百万缺陷后孵化出来。核心卖点是“确定性工程 × Agent”混合架构：文件选取、分组打包、规则匹配、评论定位这些“不能错”的环节由工程逻辑硬约束，Agent 只负责动态决策与上下文检索；自带多语言规则集（空指针、线程安全、XSS、SQL 注入等），兼容 OpenAI 与 Anthropic 模型。用法是 npm install -g @alibaba-group/open-code-review 后 ocr review，也支持整库扫描、CI 集成与委托模式（让宿主 Agent 自己跑评审，不用另配 key）。自带 AACR-Bench 基准：50 个流行开源仓库、200 个真实 PR、80 多位资深工程师标注 1,505 个问题，称同模型下比通用 Agent 精确率与 F1 更高、token 仅约九分之一。2026 年 5 月建仓，已有 857 次提交、147 个版本。

💡 点评：Skills 热潮的另一面——大家都在给 Agent 加技能，阿里反其道而行之，给评审流程加“硬约束”；当评审质量不稳定、行号漂移成为通用 Agent 的通病时，这套“工程兜底、Agent 补位”的思路值得所有做 Agent 工具的人参考。（基准成绩系项目方自述，未经独立验证。）

openai/codex-security

安全扫描Codex 官方CLI + SDKApache-2.0
今日新增 751 星，总星数 13,122，Fork 1,023；日榜第三，较昨日 643 星继续走高

OpenAI 的 Codex 安全扫描 CLI 与 TypeScript SDK，找漏洞、验证发现、生成补丁一条龙：npm install -g @openai/codex-security 后 cs scan . 即可扫描仓库、指定路径或 Git 变更，深度扫描会重复标准扫描并去重；能起草 SECURITY.md、保存威胁模型、导出 SARIF/JSON/CSV，对接 Linear、Jira、GitHub，还有 GitHub Action 与 Docker 批量扫描。模型不只限 OpenAI，也支持 Bedrock、OpenRouter、Fireworks 等。2026 年 7 月建仓，已有 2,047 次提交、55 个版本。

💡 点评：和 Cloudflare 的 security-audit-skill（本周 +8,829 星）同题竞逐——一边是 OpenAI 官方的“扫描 + 修复 + 云端”全套工具链，一边是 Cloudflare 的开源技能；安全正在成为 Agent 技能库里竞争最激烈的赛道。

we-promise/sure

个人理财社区复活自托管AGPL-3.0
今日新增 925 星，总星数 14,731，Fork 1,118；日榜第五，连续两日近千星

开源个人理财应用，源头是 Maybe Finance——这家创业公司 2021–2022 年花近 100 万美元做出全功能财富管理应用（含真人理财顾问功能），2023 年中停更后开源；社区 2025 年 7 月接手 fork 成 Sure 继续维护，已有 4,138 次提交、24 个版本。可 Docker 自托管，覆盖浏览器、macOS 桌面、移动端、API 与 LLM 客户端，一键部署到 Render、PikaPods。口号“for everyone (by everyone)”直指痛点：理财数据自己掌控、不用交订阅费。

💡 点评：商业失败、社区接盘、越活越好——Sure 是开源“复活”叙事的最新样本；当订阅制理财 App 涨价不断时，“数据主权 + 零订阅”的需求正在变成实打实的星数。

tailscale/tailcat

网络工具Tailscale 数据面无需账号BSD-3-Clause
今日新增 256 星，总星数 9,449，Fork 430；日榜第十

Tailscale 官方出品的“没有 Tailscale 的 Tailscale”：把 Tailscale 开源组件 remix 成 netcat，用 WireGuard 加密的数据面（magicsock）在两台机器间建点对点隧道，连接元数据带外交换，不用 Tailscale 账号、不用控制面、不改路由表、不需要 root。一端 tailcat 监听拿到一串短地址，另一端 tailcat <地址> 就能传 stdin/stdout、暴露本地端口、跑公钥 SSH、传文件（tailcat cp 本质是走隧道的 scp），还能当出口节点用。默认用 Tailscale 免费限速 DERP 中继打洞，也可自建；另有浏览器版 WASM 演示。2024 年 10 月建仓。

💡 点评：把企业级组网能力拆成一把瑞士军刀——临时传文件、远程调一台没装 Tailscale 的机器、给内网服务开个加密口子，tailcat 是那种“装一次、用十年”的工具。

💡 点评：八年老工具突然单周涨 1.3 万星，说明“查自己在网上留了多少痕迹”正在变成大众需求；顺手跑一遍自己的用户名，看到的注册地图多半和想象的不一样。
