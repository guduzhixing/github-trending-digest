dream-num/univer

Office SDK表格文档AI AgentApache-2.0
今日新增 988 星，总星数 25,600，Fork 2,339；日榜第一

DreamNum 出品的开源 Office SDK：把真正能算公式的表格、文档、幻灯片嵌进自己的产品，而不是再套一层 Google Sheets 或商业表格控件。核心是微内核加插件架构、Canvas 渲染与自研公式引擎（500 多个函数），同一套 Facade API 在浏览器与 Node.js 无头运行时通用。9 月 24 日发布 1.0 后团队把定位改成“The Office Harness for AI Agents”：Agent 通过结构化 API 读写表格文档，在隔离的 worktree 草稿里改、由人审阅合并，还能截图校验结果。它是该团队旧项目 Luckysheet（约 1.66 万星，已归档）的继任者。注意开源核心只含基础编辑与计算，实时协作、导入导出 xlsx、图表与透视表属于付费的 Univer Pro 层。

💡 点评：当 Agent 开始替人做表、写文档，就需要一个“Agent 能读写的 Office”；Univer 押的就是这个缺口。连续多日近千星，说明“给 Agent 配办公套件”已从概念变成采购清单上的一项。

backnotprop/plannotator

Agent 审阅批注反馈本地优先Apache-2.0
今日新增 866 星，总星数 11,823，Fork 1,082；日榜第四，本周新增 1,719 星

给编码 Agent 补“人工复核层”的本地浏览器工具：通过插件与钩子接进 Claude Code、Codex、Copilot CLI、Gemini CLI、OpenCode、Kiro、Droid、Amp、Pi 等 Agent，当 Agent 拿出方案、写完代码或生成 HTML 成品时，自动在浏览器里打开审阅面——你可以直接在方案、Markdown、HTML 或 diff 上批注，点一下发送，意见就作为下一轮输入回给 Agent。还支持 Git、GitButler、Jujutsu、Perforce 与 GitHub/GitLab 的 PR/MR 审阅，以及一个 Inbox 收拢多 Agent 的提问与文件。数据默认只留本地、不采集使用统计。作者 backnotprop 本人也在今日开发者榜上。

💡 点评：Agent 越能干，人越需要一个“看一眼再放行”的地方；plannotator 把 code review 的手感搬到了人机协作里。日周双榜齐涨，是多 Agent 并行干活正在变成常态的侧证。

alibaba/open-code-review

代码评审LLM Agent阿里巴巴混合架构
今日新增 691 星，总星数 52,061，Fork 4,109；日榜第六，连续三日高位

阿里巴巴开源的代码评审工具，主打“确定性流水线 + LLM Agent”的混合架构：先用确定性规则做精确的行级检查，再由 Agent 做语义判断，内置多语言规则集，覆盖空指针、线程安全、XSS、SQL 注入等常见问题，兼容 OpenAI 与 Anthropic 的模型接口。卖点是“在阿里规模下经过实战检验”——大厂内部评审工具开源，天然自带可信度背书。昨日新增 893 星、今日 691 星，热度没有一日游。

💡 点评：代码评审是 Agent 落地最先被验证的场景之一；阿里把内部工具开源，等于把“Agent 审代码”这件事的门槛又拉低了一截。适合想在 CI 里加一层 AI 评审的团队关注。

Tencent/LoopForge

Agent 编排团队交付自托管MIT
今日新增 423 星，总星数 1,464，Fork 264；日榜第七，11 月 15 日刚开源

腾讯 Lighthouse 团队刚开源的自托管团队级 AI 研发协作平台，解决的是“Agent 会写代码，但不会按团队流程交付”的断层：用户用一句话向 Main Bot 提需求，平台在 Docker 沙箱里拉代码、按角色分工（规划、实现、评审、测试）编排 CodeBuddy、Codex、Claude Code 干活，全程留痕、关键节点设人工审批，最后开 PR；跑通的工作方式可以存成 SOP（标准作业程序），下次同类需求照此复用。另有 LoopForge Local：一行 npx 命令把同一套分阶段交付流程装进已有的 Claude Code、Codex、Cursor、CodeBuddy 或 Pi，85 个文件、不需要服务器。注意提示词主体目前是中文，11 月 9 日至 13 日已连发五个版本。

💡 点评：从“一个 Agent 帮我写代码”到“一套 SOP 管一群 Agent 交活”，LoopForge 是大厂把内部研发流程产品化的典型动作；总星数还小，但刚开源一天就上日榜，值得持续观察。

NVIDIA/SkillEvaluator

技能评测Agent Skills三层框架Apache-2.0
今日新增 122 星，总星数 1,665，Fork 228；日榜第十二，11 月 13 日刚发 v0.9.0

英伟达开源的 Agent 技能评测框架，回答的是技能潮里最缺的一问：这个 SKILL.md 到底有没有用。三层各司其职：Tier 1 静态质检（格式、密钥与 PII 扫描、隐藏 Unicode、脚本 lint，集成 SkillSpector 做安全扫描）；Tier 2 语义去重（技能之间是否重复）；Tier 3 实测（在沙箱里让 Agent 同一任务跑两次——装技能与不装——算出 Skill Lift 提升值）。配套论文（arXiv:2608.20614）称 947 组配对实测平均 Skill Lift 为 0.2134，72.8% 的技能确有正向提升；官方博客称 300 多个已验证技能平均正确率提升 41 分。标注为 Experimental（实验性，无 SLA），Tier 1 不用 API key 就能跑。

💡 点评：技能从“人人都会写”走向“写完要测”，评测框架是生态成熟的标志；不过论文里的提升数字来自英伟达自家已验证技能目录，别直接当成自己技能的承诺。写技能、管技能库的团队可以先从 Tier 1 用起。
