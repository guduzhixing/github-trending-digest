anthropics/claude-plugins-official

日榜第 2 · 新面孔PythonApache-2.0
今日 +307 星 · 总 39,073 星

Anthropic 官方维护的 Claude Code 插件目录——官方版"应用商店"。仓库分两块：/plugins 是内部团队维护的插件（12 语言 LSP 支持、PR 评审工具、git 工作流自动化、输出格式化、代码质量检查）；/external_plugins 收录第三方伙伴（GitHub、GitLab、Linear、Asana、Firebase、Playwright、Terraform、Discord 等），提交需过质量与安全审核（表单在 clau.de/plugin-directory-submission）。安装方式标准化：/plugin install {plugin-name}@claude-plugins-official，或在 /plugin > Discover 浏览；该仓库在首次打开 Claude Code 时自动加入。插件结构也有统一契约：.claude-plugin/plugin.json 元数据 + 可选的 .mcp.json、commands/、agents/、skills/、hooks/ 目录。官方明确警告：即使收录插件也可能加载未验证的第三方软件（MCP server、文件等），安装前务必确认信任。仓库创建于 2025 年 11 月，2026 年 5 月正式公开后约 5 个月冲到 3.9 万星。

💡 点评：插件生态从散装 marketplace 走向官方策展，是 skills 大爆发后的必然一步。正在搭 Claude Code 工作流的团队，先逛官方目录再造轮子；但"官方收录 ≠ 代码审计"，生产环境装插件前看一遍仓库变更。

obra/superpowers

日榜第 6 · 新面孔Shell许可证请以仓库为准
今日 +582 星 · 总 299,878 星

给 coding agent 的"完整软件开发方法论"，装在一组可组合的 skills + 引导指令里。工作流很工程派：开工不急着写代码，先追问你到底想做什么（brainstorm），把设计拆成能读完的小块给你确认；然后做一份"给没品味、没上下文、讨厌测试的初级工程师也能执行"的计划，强调真·红绿 TDD、YAGNI、DRY；一声令下进入 subagent-driven-development：每个任务派新鲜 subagent 做，两阶段评审（先合规、再质量），agent 可连续自主跑几小时不偏航。技能自动触发，不需要特殊操作。支持十余种 agent：Claude Code、Codex、Cursor、Gemini CLI、OpenCode、Qwen Code，以及 Pi（pi install git:github.com/obra/superpowers）。作者是 Jesse（obra）。总星数逼近 30 万，是今日榜单上基本盘最厚的项目，月榜/周榜同样常年在线。

💡 点评："方法论 > 工具"在 agent 时代被反复验证。agent 写代码越能干，人类侧缺的越是纪律——superpowers 就是把代码评审时代的工程纪律编译成 agent 能执行的指令。想让 agent 长期维护项目的团队值得完整装一套试试。

"agent harness 性能优化系统"：136 个 skills、36 个 agent、68 条命令、若干 hooks，横跨 Claude Code、Codex、OpenCode、Cursor、Gemini、Zed、GitHub Copilot。核心是一套"反遗忘"设计：计划先变成可编辑的产物、确认后再开工；TDD 做成带证据的红绿重构门控，而不是一句会被模型忘记的口头要求；评审用新鲜上下文的 agent 找盲区；会话被蒸馏成摘要 + instincts + 可复用 skills（持续学习、带置信度评分、可导入导出）；hooks 在提示词之外做确定性检查；AgentShield 把 harness 本身当攻击面扫描。多语言 README（含简体中文），v2.0 补了跨 harness 架构与 Hermes operator 故事。仓库首页特别声明：只从官方渠道安装（GitHub 仓库、npm 包 ecc-universal / ecc-agentshield、GitHub App、插件 slug ecc@ecc、官网 ecc.tools），第三方 re-upload 可能含恶意软件。

💡 点评：和 superpowers 同属"给 agent 立规矩"赛道，但 ECC 更重——它是 harness 级操作系统。生态位清晰：superpowers 讲纪律，ECC 讲装备。注意它的安全声明本身也是信号：热门到被仿冒，装之前核对官方渠道。

JuliusBrussee/caveman

日榜第 4 · 新面孔Go拆分许可（skill MIT，运行时部分 BSL-1.1，详情以仓库为准）
今日 +433 星 · 总 112,527 星

"why use many token when few token do trick"——2026 年 4 月一个周五的玩笑起家，一周拿下 4000 星，现在 11.2 万星，还攒出一篇研究论文（Adobe Research 引用：caveman 风格输出让 8 个模型便宜 1.4~2.4 倍）、JetBrains 实验室 A/B 测试、Primeagen 反应视频、HN 第一。打法分三层：skill 是一份规则文件（MIT，30+ agent 通用），让 agent 用洞穴人式短句回答，代码/命令/报错逐字节不动，输出 token 省约 65%（项目口径，10 提示词测试套件）；本地 Go 代理压缩 agent"读"的内容（日志、测试输出、JSON、diff、搜索结果），每字节本地备份可恢复，Claude Code 基准输入 -33.2%、18/18 正确性通过；middleware 则包进你自己的 LangChain / Anthropic / OpenAI 调用。分级模式 /caveman，还附赠文言文风。注意：CLI 默认匿名遥测（caveman telemetry off 或 DO_NOT_TRACK=1 关闭）；skill 只省输出，每轮固定多花约 1~1.5k 输入 token，本就简洁的任务可能不赚。

💡 点评：token 是 agent 规模化最显性的账单，caveman 把"省 token"做成了基础设施层。玩笑外壳、基准认真的项目最难复制——因为它同时吃到了传播红利和工程可信度。

ruvnet/ruflo

日榜第 7 · 新面孔TypeScriptMIT（核心开源）
今日 +147 星 · 总 75,112 星

自称"原初 agent harness"（前身 Claude Flow），10 月 13 日其背后的 Cognitum One 刚宣布新版：Ruflo Mods（一个 mission 生成端到端工作流：研究→构建→测试→验证→安全→基准→学习）+ 单一控制平面（swarm、智能、安管、运维、扩展网络统一编排，关键处人工审批）。核心理念 "Agent = Model + Harness"：模型负责推理写代码，harness 给工具、记忆、循环、沙箱、控制。一个 npx ruflo init 把 Claude Code / Codex 变成 100+ 专业 agent 的蜂群（planner、coder、tester、reviewer、security、docs 分工），配向量记忆（AgentDB/HNSW）、跨 provider 模型路由、跨机器联邦（PII 门控）、SONA 自学习记忆、314 个 MCP 工具、35 个插件（ruflo-core / swarm / autopilot / workflows / federation / rag-memory…）。公司口径：生态 12 个月 1250 万 npm 下载，ruOS 企业平台也在用它做 agent 编排。

💡 点评：swarm 坐标系里 ruflo 和 caveman 是两极——一个做大（更多 agent 协同），一个做省（更少 token）。想试的话按官方建议从有边界的只读任务开始，先看 Console 的 cost 视图再加 agent；联邦默认按对抗模型对待，PII 门控要在真实流量上验证后再信。
