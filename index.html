官方市场CursorTypeScript

Cursor 官方的插件规范 + 官方插件仓库，年初 1 月 23 日创建。README 列了上百个官方插件：开发者工具类有 orchestrate（任务扇出到并行云 agent）、thermos（硬核代码评审）、pstack / dyl-stack（agent 工作流方法论）、ralph-loop（Ralph Wiggum 自迭代循环）、cli-for-agent（给 agent 设计 CLI 的规范）、cursor-sdk；生产力类一口气覆盖 Gmail / Drive / 日历 / Docs / Sheets / Slides / Teams / SharePoint；集成类更重：GitHub、Playwright、X、Salesforce、HubSpot、Zoom、BigQuery、S&P Global、Xero、QuickBooks，乃至 Robinhood / Coinbase / Interactive Brokers / eToro 等券商账号。仓库根目录同时放着 .cursor-plugin、.claude-plugin、.codex-plugin 三套清单——Cursor 把插件做成了跨 agent 的标准分发格式。

💡 点评：和 Anthropic 的官方插件目录（昨日重点，今日周榜继续爬到第四）打擂台，插件市场正式进入"官方下场卷生态"阶段。Cursor 用户可以重点看 cli-for-agent 和 agent-compatibility 这两个：一个教你怎么设计 agent 可用的 CLI，一个给仓库做兼容性扫描。

storytold/artcraft

AI 艺术艺术家 IDEApache-2.0/MIT 双许可Rust
周榜 +16,379 星（第二名），总星 32,711，fork 5,185 —— 本周新增星数占总星数一半

"The IDE for artists"：一个面向艺术家、设计师、电影人的交互式 AI 图像/视频创作桌面应用。核心理念是把 prompting 变成 crafting——先搭场景再生成：Image to Location（把虚拟演员放到固定场景多机位拍摄）、3D 图像合成（前后景 + 道具分层）、角色摆姿 + 相机预设、kitbashing 场景搭建（组合 3D 素材包控制机位）、角色身份迁移（用摆好姿势的假人引导角色姿态）。模型目录列了 62 个：图像 16 款（Nano Banana 全系、GPT Image、FLUX、Seedream）、视频 25 款（Kling、Veo、Sora、Seedance、MiniMax、Vidu）、音乐 5 款（Suno）、3D 网格 11 款（混元 3D、Tripo3D、Meshy、Rodin）、世界生成 5 款（World Labs Marble）。仓库 2022 年就建了，是老项目转向 AI 创作赛道后的爆发。

💡 点评：今天榜单里难得的非开发者工具爆款——AI 创作工具正在从"提示词彩票"转向"可控制作流程"，这和昨天 CLI-Anything 的"让 agent 操控软件"其实是同一趋势的两面：控制力。做短视频、独立游戏美术、概念设计的可以去 getartcraft.com 下桌面版试玩，Windows/macOS 稳定版，Linux 需源码编译。

heygen-com/hyperframes

AI 视频程序化渲染Apache-2.0TypeScript
周榜 +5,883 星，总星 66,728，fork 6,050；月榜 +15,429 星

HeyGen 开源的框架："Write HTML. Render video. Built for agents."——用 HTML/CSS/可寻址动画写视频脚本，渲染成确定性 MP4。技术栈是 Puppeteer + FFmpeg，动画层支持 GSAP / Lottie / Three.js / Anime.js / CSS / WAAPI，讲究"可 seek、确定性"，渲染两次结果一致。配套 21 个 agent skills 按需加载：/hyperframes 是总路由器，创作流有 product-launch-video（产品发布片）、pr-to-video（PR 链接转 changelog 解说视频）、talking-head-recut（口播视频加包装）、music-to-video（音乐卡点）、slideshow 等；还有个 frame.md 概念——把品牌设计规范翻译成"为镜头而写"的版本，让 agent 不用猜尺寸。另外一个细节：README 专门写了 HyperFrames vs Remotion 对比页，目标很明确——抢 Remotion 的"代码做视频"地盘。

💡 点评：和 ArtCraft 恰好互补：一个给艺术家可视化搭场景，一个给 agent 写代码渲视频。做自动化内容管线（PR 自动转解说、数据报表自动转视频）的人值得重点关注；npx hyperframes init 一条命令就能起本地工程。
