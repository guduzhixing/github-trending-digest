obra/superpowers

Agent Skills开发方法论Claude Code
今日新增 883 ⭐ · 总星 323,719 · Fork 28,713 · 日榜第 2
💡 全榜总星最高的项目，32 万星仍每天吸走近 900 星。作者 Jesse Vincent（obra）2025 年 10 月发布，把 30 年软件工程方法论压进一套可组合的技能：先头脑风暴问清真实需求、分块确认设计文档，再用 git worktree 隔离开发分支，把计划拆成 2–5 分钟一个的小任务，每个任务带精确文件路径、完整代码与验证步骤；执行时每个任务派一个全新子 Agent，逐任务做两轮评审，最后强制红绿重构 TDD——没先写测试的代码会被删掉。支持 Claude Code、Cursor、Codex、Gemini、Pi 等多家 Agent，已进 Anthropic 官方插件市场。适合想把 AI 编程从“随手写一段”升级为“可交付、可评审流程”的开发者；流程偏重，小修小补直接用会嫌啰嗦。

HKUDS/CLI-Anything

Agent 原生化CLI 生成港大 HKUDS
今日新增 769 ⭐ · 总星 62,069 · Fork 5,631 · 日榜第 3 · Python 榜第 2
💡 港大 HKUDS 团队出品，解决的是“Agent 怎么用没有 API 的软件”这个根本问题：不教 Agent 去点鼠标，而是用七阶段自动化流程（分析、设计、实现、测试规划、写测试、文档、发布）把任意软件包成结构化 CLI，输出确定性 JSON，自动生成 SKILL.md 供 Agent 阅读。配套 CLI-Hub 像个应用商店：cli-hub install gimp 一条命令就能装好现成接口，已覆盖 Blender、GIMP、LibreOffice、Obsidian、Godot 等 80 多个应用，生成出来的 CLI 调的是软件真实后端——Blender 是真渲染、LibreOffice 是真出 PDF。另有 arXiv 技术报告背书。适合想让 Agent 真正操作桌面软件、做自动化工作流的开发者与团队。
