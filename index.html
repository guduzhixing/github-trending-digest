Nutlope/hallmark

Agent Skill🏷 AI 设计🏷 反套路
日新增 455 星 · 总星数 32,129 · 日榜第 4
💡 Together AI 出品的反 AI 套路设计 skill，解决的是一个所有人都见过的问题：让 agent 生成页面，十次有九次是紫色渐变 hero、Inter 字体、三张并排卡片。Hallmark 不给组件、不给样式库，只给规则：先按简报选页面骨架，再套二十余套主题，出厂前跑一套反套路自检和自我批评，不合格就重做。四个动词覆盖全流程：默认新建、audit 只打分不改代码、redesign 保留文案换骨架、study 从截图或网址提取可复用的设计 DNA。安装只需一条 npx 命令，支持 Claude Code、Cursor、Codex，MIT 协议。适合天天让 agent 出页面的开发者和独立开发者。提醒：规则再严也代替不了真实内容，没有真实数据时它会留待确认字段，别指望它替你编数字。

pbakaus/impeccable

Agent 工具🏷 设计语言🏷 开源大厂背书
日新增 619 星 · 总星数 86,393 · 日榜第 6；月新增 15,700 星
💡 和 Hallmark 同日上榜、同一个靶子，但打法不同：如果说 Hallmark 是禁令清单，Impeccable 就是设计词汇表。作者 Paul Bakaus 是 jQuery UI 的创造者、前 Google 工程师，他的判断是：AI 出不了好设计，不是因为不会写代码，而是没有设计师的语言——说不出哪里不对，就只能加渐变、加阴影。Impeccable 给 agent 一组设计命令和七类参考指南，覆盖排版、色彩与对比度、空间、动效、交互、响应式和 UX 写作，支持审计、批评、打磨和优化，装进 Claude Code、Cursor、Copilot、Codex 等主流 harness，Apache-2.0 协议，现已随新版 GitHub Copilot 应用内置。适合对 AI 生成 UI 质量有硬要求的团队。注意：它给的是审美判断力，不是审美本身，最终拍板还得有人。

makecindy/cindy

Agent 客户端🏷 多 harness🏷 开箱即用
日新增 477 星 · 总星数 4,090 · 日榜第 10
💡 口号是“想到，就能做到”的开源 AI agent，卖点不是又一个模型，而是一层控制层：把 Claude Code、Codex、Pi 等多个 harness 装进同一个本地客户端，模型和 harness 可以任务中途自由切换，工作区、记忆、skill 和工具不断线；一个任务还能先由一路 agent 做规划，再由多路不同 harness 与模型组合并行执行、最后由另一路独立评审。客户端是桌面加移动端的 pnpm 单仓，Apache-2.0 协议，可接官方服务、已付费的 Claude Code 或 Codex 订阅、自带 API Key 或本地模型，也能驱动浏览器、电脑和手机，从 IM 和日程接活。适合同时付费多个 agent、又不想每次换工具就重开任务的人。诚实说明：这个仓库开源的是客户端，服务端在另一个仓库，完整能力依赖服务侧。

stablyai/orca

Agent 编排🏷 并行舰队🏷 开源
周新增 9,828 星 · 总星数 104,952 · 周榜第 5，总星数突破 10 万
💡 如果 Cindy 是“一个任务换着用多个 agent”，Orca 就是“一个任务同时派多个 agent 去做，赛马选 winner”。它本身不是 coding agent，而是编排层：把同一提示同时发给 Claude Code、Codex、Grok、Cursor、Copilot、OpenCode 等几十种 CLI agent，每个跑在独立的 Git worktree 里，互不覆盖文件，做完后并排对比、合并最优结果，其余丢弃。桌面、移动端和远程运行时齐全，手机端能盯进度、发追问，SSH worktree 能把 agent 派到远程机器上，MIT 协议。适合已经为多个 agent 付费、想用并行换确定性的重度用户。成本提醒：Orca 本体免费，但每个 agent 都烧你自己的订阅或 API 额度，舰队越大账单越实在。

Graphify-Labs/graphify

Agent 工具🏷 知识图谱🏷 代码理解
周新增 6,868 星 · 总星数 134,466 · 周榜第 13，新上周榜
💡 把整个代码库连同文档、SQL schema、配置和 PDF 变成一张 agent 可查询的知识图谱，装成 /graphify skill 跑在 Claude Code、Cursor、Codex、Gemini CLI 等十余种 harness 里。核心选择很克制：代码一律本地用 tree-sitter 做确定性 AST 解析，不调模型、不出本机；每条边都标注来源，是直接从源码读到的还是工具推断的，查得到出处；不做 embedding、不建向量库，回答是一条带文件行号的显式路径，而不是“看起来像”的前 k 个片段。一次运行产出可交互的 graph.html、一页纸的 GRAPH_REPORT.md 和完整的 graph.json，还能走 MCP 被查询，Apache-2.0 协议。适合接手大型遗留代码库、做影响面分析的人。注意：文档和 PDF 的语义提取仍要走你助手背后的模型，纯本地只覆盖代码部分。
