morluto/rea

AI Agent逆向工程MITTypeScript
周榜 +239,923 星，总星 307,589，fork 77,824 —— 断层式周榜第一

REA（Reverse Engineer Anything）是一个 MCP 服务器 + CLI，让 Claude Code、Codex、Cursor 等编码 agent 直接调用 Ghidra、IDA Pro、Hopper 这类专业逆向工具。开发者用自然语言问"这个 App 的搜索功能怎么实现的"，agent 返回伪代码、模块关系图和执行轨迹，每条结论都带证据。项目 2026 年 4 月创建，前半年默默无闻不足 1 万星；10 月 8 日 v6.0 发布（离线 EVM 字节码审查、pwntools 崩溃分析、LLDB 调用追踪、Ghidra 支持 Windows x86）后彻底点火，Replit CEO Amjad Masad 和 Matthew Berman 那句"Software is done"（约 350 万播放）把它推上风口，HN 帖子冲到 764 分、325 条评论，两周拿下 25 万星。

💡 点评：README 写得很诚实——它不是"一键克隆 App 按钮"，恢复不了源码、碰不到服务端逻辑。但在 Electron/JS 应用和 agent 辅助的 Ghidra 工作流上是真好用，安全研究、恶意软件分析、互操作性开发的从业者值得装一个。注意只分析自己有权限的软件，以及提防冒充的山寨仓库（官方安装走 npx rea-agents setup）。

debpalash/VoiceStudio

本地语音开源 ElevenLabs 替代AGPL-3.0Python
日榜 +2,125 星，月榜 +40,333 星，总星 73,332，fork 8,026 —— 今日日榜增速第一

VoiceStudio 是开发者 Palash Debnath 的作品（前身叫 OmniVoice-Studio，2026 年 4 月创建），把 17 个本地 TTS 引擎和 11 个转写引擎装进一个桌面应用：声音克隆、声音设计、视频配音、听写、转写、有声书制作，号称支持 646 种语言，默认引擎是 k2-fsa 的 OmniVoice。关键点不只是"免费本地版 ElevenLabs"——它自带本地 REST API 和 MCP 服务器，Claude Code 里的 agent 可以直接调用它生成旁白、转写文件，音频不出本机，一句 npx skills add debpalash/VoiceStudio 就能把语音能力装进 agent。

💡 点评：做播客、短视频配音、视频本地化的人可以直接省掉云端语音订阅；对 agent 开发者来说，它是"给 agent 装上嘴和耳朵"的现成零件。注意许可证是 AGPL-3.0，商用集成前先看条款，模型本身还保留各自上游许可。

xerj-org/xerj

Agent 检索Rust单体二进制Elasticsearch 兼容
日榜 +1,160 星，总星仅 7,787 —— 总盘子最小、增速最陡的异常值

XERJ 把自己定位成"为 AI 而生的搜索引擎"。痛点很具体：编码 agent 面对几十万行代码只能 grep，而 grep 只告诉你"在哪看"，agent 还得把整文件读进上下文烧 token。XERJ 是一个 Rust 单体静态二进制，一条 xerj autoindex 用 tree-sitter 把代码、文档、日志、PDF 建成索引，agent 用 xerj search/xerj def 直接拿到函数定义和调用契约。官方给出的实测数字：检索比 grep 驱动的 agent 少用 2.7 倍输出 token（输出 token 是贵的），跨文件基准测试中首文件命中率 94% 对 38%。同时兼容 Elasticsearch 8.x API，老客户端不用改。

💡 点评：token 经济学正在变成 agent 工具的核心卖点，"比 grep 省 40 倍 token"就是冲着这来的。适合本地知识库、代码库 RAG 和 agent 记忆场景的人试用；40x 这类 headline 数字看看就好，2.7x 那组对照实验反而更可信。

HKUDS/CLI-Anything

Agent-Native港大实验室Apache-2.0Python
日榜 +574 星，总星 54,052，fork 4,905，145 位贡献者

这是香港大学数据智能实验室（HKUDS）的作品，口号是"Making ALL Software Agent-Native"。思路很直接：Claude Code 能读写文件跑命令，但操作不了 Blender、Zoom 这类没有官方连接器的 GUI 软件——CLI-Anything 让 agent 自己给目标软件生成一套类型化 CLI（/cli-anything ./gimp 一条命令走完分析、设计、实现全流程，带 REPL、JSON 输出、撤销重做），已有 GIMP、Blender、Audacity、LibreOffice、OBS、Zoom、ComfyUI 等 13 款软件的现成封装，另有 CLI-Hub 让 agent 自主发现、安装所需的 CLI。

💡 点评：学术界下场做 agent 基础设施，而且是被 arXiv 论文引用的那种，含金量不低。它和 REA 恰好互补：一个让 agent"看懂"软件，一个让 agent"操控"软件。做桌面自动化、批量媒体处理的人可以直接去 CLI-Hub 淘现成 CLI。

anthropics/claude-plugins-official

官方市场Claude CodePython
日榜 +1,397 星，总星 41,741，fork 4,464；周榜从第 10 冲到第 5

Anthropic 官方维护的 Claude Code 插件目录，也是 Claude Code 首次启动交互会话时自动装好的那个市场。里面有 Anthropic 自家出的 security-guidance（写代码时实时 flagged 风险操作）、code-review（读 diff 的 subagent）、各语言 LSP 插件（TypeScript 真类型检查、跳转定义，不再靠猜），以及合作伙伴的 Playwright（浏览器 E2E）、Context7（实时版本文档）等，全目录 200+ 插件。安装就是 /plugin marketplace add anthropics/claude-plugins-official。

💡 点评：插件生态正在成为 Claude Code 的护城河，官方目录的星数增速说明"先装插件再开工"已经变成标准动作。新用户建议先装 security-guidance 和 code-review 这两个，投入产出比最高。
