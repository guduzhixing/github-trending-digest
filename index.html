Donchitos/Claude-Code-Game-Studios

Shell游戏开发Claude Code 模板多 Agent 协作
今日新增 742 星，总星数 31,158，Fork 4,268；日榜第三

把一次 Claude Code 会话变成一家游戏工作室：49 个专职 Agent 按总监、部门负责人、专家的三层结构分工，覆盖设计、编程、美术、音频、叙事、QA 与制作，并配有从头脑风暴到发版检查的完整工作流。它不是一个现成游戏，而是一套克隆下来即用的项目模板，支持 Godot、Unity 与 Unreal 三种引擎。它的走红点出了一个共识：单 Agent 写代码够用了，难的是把分工、评审与交付流程也交给 Agent，而游戏开发恰好是最考验这种流程的场景。

💡 点评：独立游戏开发者最值得试的一类模板，但要清醒看待它的边界——它提供的是流程与分工骨架，不是成品游戏，玩法本身仍需人来把关。

Orkas-AI/Orkas

JavaScriptAI 团队本地优先桌面应用
今日新增 1,044 星，总星数 6,156，Fork 371；日榜第十一

开源的本地优先 AI 团队桌面应用：一个 Commander 先把你的目标拆成待办，再分派给 16 个内置专家，涵盖研究、写作、办公文档、幻灯片、图片与视频，还能把已装好的 Claude Code、Codex、OpenCode 等命令行 Agent 纳入同一计划统一调度。数据、聊天记录与密钥默认留在本机，模型可用内置额度，也可接自己的供应商密钥。它火的背景很直接：当人人手里都有好几个 Agent 时，缺的不再是单个更强的助手，而是一个能把它们编成一支队伍的指挥层。

💡 点评：适合已经同时在用多个 Agent、又对数据落点敏感的用户；但“本地优先”不等于模型本地运行，模型调用仍走网络，这一点要按自己的隐私要求核对。

继续霸榜的 Agent 长期记忆层：把每次会话中 Agent 的所作所为记录下来，用 AI 压缩成结构化记忆，在未来会话中按需注入，支持 Claude Code、Codex、Gemini、Copilot、OpenCode 等多种工具。日榜第一且三榜同在前排，说明它已从“尝鲜工具”变成不少人工作流里的默认配置。当 Agent 开始承担多天、跨项目的连续工作时，上下文窗口再大也装不下全部历史，外部记忆就成了刚需——这正是它总星数突破十万后仍在涨的背景。

pbakaus/impeccable

RustAgent 技能设计评审反 AI 味
今日新增 1,338 星，总星数 98,265，Fork 5,793；日榜第七，周榜新增 12,031 星，月榜新增 25,479 星

给编码 Agent 配一套设计词汇：用 polish、bolder 打磨页面，用 critique 做带评分的可用性评审、用 audit 查无障碍与性能，另有 62 条确定性规则的“AI 味”检测器，无需大模型、无需 API Key 即可扫描。周榜与月榜的增量都排在前列，说明这波“品味热”不是一日行情：Agent 生成的页面越来越像，开发者正在用可执行的规则把审美从个人感觉变成团队标准。它同时覆盖 Claude Code、Cursor、Codex、Copilot 等二十余种工具，装上就能用。

💡 点评：做 AI 生成前端的团队值得先跑一遍它的检测器，再谈审美；规则能兜底，但替代不了真正的设计判断。

milind-soni/OpenMausBot

TypeScriptAI 机器人虚拟机Grok Bot 替代品
今日新增 1,303 星，总星数 9,601，Fork 1,329；日榜第六

开源版 Grok Bot 替代品：给机器人配一台可用的虚拟机，让它不只会聊天，还能在虚拟机里实际操作、完成任务。它的走红与 OpenBot 这类项目指向同一趋势：Agent 的竞争正在从“说得好不好”转向“能不能在真实环境里动手干活”。虚拟机这层隔离既是能力边界，也是安全边界——机器人能碰什么、碰坏了怎么办，都要先框定。需要注意的是，这类项目的能力高度依赖所接的模型与虚拟机配置，开箱表现因人而异。

💡 点评：对“机器人同事”感兴趣的开发者可以把它当作动手实验的起点，先在隔离环境里验证，再考虑接真实任务。
