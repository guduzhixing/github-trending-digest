vercel-labs/agent-desktop

Rust桌面 Computer Use无障碍树跨 Agent
今日新增 2,275 星，总星数 9,614，Fork 651；日榜第一

Vercel Labs 在 10 月底发布的桌面版 computer-use 工具：它本身不是 Agent、也不内置模型，而是一个 Rust CLI，让 Claude Code、Codex、Cursor 这类编码 Agent 通过操作系统的无障碍树读取并操作 macOS、Windows、Linux 上的原生桌面应用。Agent 不再靠截图猜像素坐标，而是拿到带引用的 JSON 界面快照，按引用点击、输入、滚动，再读一遍界面确认结果；默认不抢鼠标、不夺焦点，多个 Agent 可以并行。它是此前 agent-browser 的桌面延伸，1.0 版 10 月 27 日发布、1.0.2 紧随其后，正好撞上 Agent 从终端走向整个桌面的窗口期。

💡 点评：做桌面自动化或 Agent 工具链的人值得第一时间试；但要先接受它的硬边界——不暴露无障碍树的应用，它够不着。

今日新增 3,229 星，总星数 41,883，Fork 9,090；日榜第七、单日涨幅第一，周榜新增 9,770 星，月榜新增 15,731 星

今日单日涨星最多的项目：Theo Browne 的 Ping Labs 出品的开源 Agent 操控台，本身不卖模型、不收订阅，驱动的是你本机已有的 Codex、Claude Code、Cursor、Grok Build、OpenCode 等 Agent，把它们收进同一套桌面、网页与移动端界面。每个线程写进自己的分支，一键提交 PR；最近版本稳定了跨供应商委派子任务与 Git worktree 支持。它火的逻辑与 agent-desktop 呼应：Agent 越来越多、越来越能干，缺的不是新助手，而是一个把它们统一管起来的操作面——昨天它已是日榜常客，今天直接冲到单日涨幅第一。

💡 点评：同时在用多个编码 Agent 的开发者值得一试；但项目自认仍处于非常早期阶段，上车前要按“会遇到 bug”的预期来评估。

今日新增 1,803 星，总星数 110,730，Fork 9,653；日榜第二，周榜新增 7,255 星，月榜新增 15,681 星

连续多日霸榜的 Agent 长期记忆层：把每次会话中 Agent 的工具调用、决策与结果记录下来，用 AI 压缩成结构化记忆，在未来会话中按需注入，覆盖 Claude Code、Codex、Gemini、Copilot、OpenCode 等工具。它在日、周、月三榜同时居前，总星数突破 11 万后单日仍涨 1,800 星，说明它已从尝鲜工具变成不少人工作流里的默认配置。逻辑很直白：Agent 开始承担多天、跨项目的连续工作时，再大的上下文窗口也装不下全部历史，外部记忆就从加分项变成了刚需。

💡 点评：记忆正在成为 Agent 基础设施的标配层；上车前先想清楚两道关：记什么、不记什么，以及旧记忆出错时如何纠正。

Donchitos/Claude-Code-Game-Studios

Shell游戏开发模板多 Agent 协作Godot / Unity / Unreal
今日新增 1,379 星，总星数 33,535，Fork 4,518；日榜第五

把 Claude Code 变成一家游戏工作室的开源模板：49 个专职 Agent 按总监、部门负责人、专家的三层架构分工，配 74 个斜杠技能（README 口径），覆盖设计、编程、美术、音频、叙事、QA 与制作，另有 Godot、Unity、Unreal 三套引擎专属配置。用法是克隆仓库后在项目根目录打开 Claude Code、跑 /start，从点子一路走到可测试的游戏。项目方自己的对照实验颇诚实：流程最重的那版多写了 29 份文档，却在盲评与真人试玩中垫底——文档买来的是可追溯性，不是更好玩的游戏，轻量档才是默认档。

💡 点评：想用 Agent 做独立游戏的人可以直接拿它当脚手架；但别被 49 个 Agent 的排面迷惑，真正决定成败的仍是玩法本身。

JustVugg/colibri

C本地推理MoE零依赖
今日新增 675 星，总星数 46,524，Fork 5,378；日榜第十

纯 C、零依赖的本地推理引擎，目标是把 744B 参数的 MoE 前沿模型搬上普通消费级机器：只把约 17B 参数的稠密部分（注意力、共享专家、词嵌入，int4 约 9.9GB）常驻内存，其余两万多个路由专家（约 370GB）按 token 需要从 NVMe 磁盘按需流式加载，辅以分层 LRU 缓存与推测解码。它证明的是可行性而非速度——作者自测的低配机冷启动只有 0.05–0.1 token/秒，离实时对话还很远；但对想在本地跑前沿大模型做研究的人，它把硬件门槛从“多卡机房”降到了“一台带大硬盘的电脑”。

💡 点评：本地大模型爱好者与推理引擎开发者必看；但先算好 370GB 磁盘与龟速出词的账，再决定要不要动手。
