google-research/paper-orchestra

多 Agent论文写作Google ResearchApache-2.0
今日新增 1,524 星，总星数 4,268，Fork 531；日榜新增星数第一，较昨日 1,072 星再涨四成

Google Cloud AI Research 出品的多 Agent 论文写作框架：把未经整理的写作素材（想法、实验日志）变成可投稿的 LaTeX 稿件。五个专业 Agent 分工协作——大纲、文献综述、章节写作、内容打磨、绘图，自动检索并整合相关文献、按目标会议模板出稿，还能用代码生成图表。支持 Gemini 与 OpenAI 模型，配有 Streamlit 交互演示。仓库声明并非谷歌官方支持产品，论文配套数据集尚未随代码发布。

💡 点评：两天 1,072 → 1,524 星，涨幅本身就是信号——学术写作也开始上 Agent 流水线。写论文的研究者可以拿来试，但别指望它替你做实验与判断，成稿质量仍需人工把关。

Agent 框架性能优化系统：把技能、直觉、记忆、安全与“研究优先开发”打包成一套可落地的开发方式，面向 Claude Code、Codex、OpenCode、Cursor 等多个编码 Agent。总星数已超 30 万、Fork 数高达 4.5 万，是日榜里体量最大的项目之一，说明它早已不只是“又一个配置合集”，而是被大量开发者实际 fork 下去改着用的工作台。

mvanhorn/last30days-skill

研究技能跨平台检索趋势分析Python
今日新增 1,059 星，总星数 69,987，Fork 6,241；本周新增 2,423 星，日周双榜齐涨；作者 mvanhorn 今日开发者榜第五

一个给 Agent 用的主题研究技能：针对任意话题，横跨 Reddit、X、YouTube、Hacker News、Polymarket 与全网做检索，再综合成一份有依据的总结。卖点是“有根据”——不是让模型凭记忆编答案，而是先拉回多源材料再写结论。作者本人也在今日开发者榜上，项目与人双双上榜。

💡 点评：研究类技能是技能潮里最实用的分支之一：省掉的是人肉翻十几个平台的时间。做竞品调研、舆情追踪或选题摸底的人可以直接装上，但结论仍要抽查信源，别全信合成稿。

HKUDS/CLI-Anything

Agent 原生CLI 生成CLI-HubApache-2.0
今日新增 389 星，总星数 59,726，Fork 5,425；首次登上日榜

香港大学数据智能实验室（HKUDS）出品，口号是“让一切软件 Agent 原生”：不教 Agent 像人一样点鼠标，而是分析软件源码、把图形界面背后的真实 API 抽出来，自动生成一个结构化 CLI，让 Agent 直接用命令行驱动软件。配套 CLI-Hub 像个应用商店，一条命令安装社区做好的 CLI，已覆盖 Blender、LibreOffice、Audacity、OBS、Zoom 等软件；生成器本身是七阶段流水线，配有技术报告与 2,400 多个测试。支持 Claude Code、Cursor、Codex、Pi、OpenClaw 等多个 Agent。

💡 点评：这是技能潮之外另一条更底层的路线——与其给 Agent 配更多“用法说明”，不如直接把软件改造成 Agent 能用的样子。同实验室的 DeepTutor 也在月榜前十，HKUDS 正在批量产出 Agent 基建，值得长期跟踪。

NVIDIA/SkillEvaluator

技能评测质量门禁NVIDIAApache-2.0
今日新增 312 星，总星数 3,712，Fork 516；首次登上日榜，v0.9.0 于 11 月 13 日发布

NVIDIA 开源的 Agent 技能评测框架，也是其“Verified Skills”认证流水线的一部分。技能写出来容易，难的是知道它写得规不规范、有没有安全隐患、是不是在重复已有指导、以及到底有没有让 Agent 变强——这个工具分三层回答：第一层静态验证（格式、质量打分、密钥与 PII 扫描、注入风险检查）；第二层用嵌入向量做语义去重，找出技能内与技能间的重复指导；第三层最关键，在沙箱里让真实 Agent 同一任务跑两次（装技能与不装技能），差值记为 Skill Lift。配套论文已发 arXiv。支持 GitHub Actions 与 GitLab CI，一条命令可接入 PR 门禁。

💡 点评：技能潮走到今天，缺的不是技能，是验货标准。NVIDIA 把“技能有没有用”从感觉变成了可测量的数字，写技能、维护技能库的团队都该装一个跑跑自己的库——先过第一层静态检查，成本最低。
