shadcn/improve

Agent Skills代码审计模型分工MIT
今日新增 361 星，总星数 10,855，Fork 443；日榜第四

shadcn（shadcn/ui 作者）的新作，一个 Agent Skill，核心理念是“把智能用在会复利的地方”：让最强的模型做理解代码库、判断优先级、写实施方案，执行则交给更便宜的模型，技能本身一行代码都不改，只产出计划。用法是 npx skills add shadcn/improve 后跑 /improve，它会并行派子 Agent 按正确性、安全、性能、测试覆盖、技术债等九个维度审计，逐条核对引用位置后给出按“影响 ÷ 成本”排序的发现表；选中的发现写成 plans/ 下自包含的 Markdown 方案，内含代码摘录、仓库自己的测试命令作验收关卡和 STOP 条件。/improve execute 还能在隔离 worktree 里派便宜模型执行并像 tech lead 一样审 diff。2026 年 6 月建仓，MIT 开源。

💡 点评：Skills 热潮里最有方法论含量的一支——它不卖“更强的 Agent”，卖的是“怎么分工才不烧钱”；审计与执行分离，正是 Agent 落地时最先撞上的成本墙。

openai/codex-security

TypeScript安全扫描CodexApache-2.0
今日新增 52 星，总星数 11,706，Fork 937；日榜第九

OpenAI 官方的 Codex 安全工具：CLI（cs）加 TypeScript SDK，帮你发现、验证并修复代码漏洞。cs scan . 扫整个仓库，也可只扫指定路径、diff 或跑深度扫描；找到候选漏洞后会验证、生成补丁并复核已有修复，还能起草 SECURITY.md、保存威胁模型、导出 SARIF/JSON/CSV 接入 Linear、Jira 或 GitHub。另有 GitHub Action 可每周定时扫描（示例单次扫描预算约 5 美元），并支持 Bedrock、OpenRouter 等非 OpenAI 模型。2026 年 7 月建仓，Apache-2.0 开源，已发 53 个版本。

💡 点评：AI 写代码越多，AI 审代码的生意就越大；OpenAI 把安全扫描做成 Codex 的一等公民，等于承认“生成之后必须有验证”正在成为标配流程。

vercel-labs/agent-browser

Rust浏览器自动化Agent 工具Apache-2.0
今日新增 708 星，总星数 49,852，Fork 3,488；日榜第六，周增 4,183 星

Vercel Labs 的 Agent 浏览器自动化 CLI：Rust 原生命令行，用 snapshot 把页面转成带 @e1 这类引用的紧凑无障碍树，Agent 按引用操作、再快照确认，浏览器在命令之间保持开启，一步就是一次短 shell 调用。支持 Chrome for Testing、Lightpanda、Obscura 等引擎，可接云端浏览器厂商，也能以 MCP 服务器形式供 MCP 客户端调用，还自带与 CLI 版本匹配的 skills。姊妹项目 agent-desktop（桌面级 computer use）本周新增 7,772 星、总星数 22,059，两个项目一横一纵，Vercel 正在把“Agent 的手”做成一套完整工具链。2026 年 1 月建仓，Apache-2.0 开源，已发 121 个版本。

💡 点评：Agent 要替人办事，先得有一双能点、能填、能等的“手”；agent-browser 把浏览器操作压成 shell 命令，是目前最合 Agent 胃口的交互形态。

cloudflare/security-audit-skill

Agent Skills安全审计对抗验证MIT
周增 11,507 星，月增 42,138 星，总星数 70,359，Fork 4,666；本周增量全榜第一

Cloudflare 开源的安全审计技能，源头是该公司内部漏洞发现流水线的起点。流程分六个阶段：侦察建架构与覆盖台账、多路隔离猎手按台账找漏洞、每个候选发现交给全新验证者去“证伪”、结构化输出 findings.json（confirmed / needs_validation / rejected 三档）、独立 Agent 再验一遍源码引用、最后生成目标中立的报告。设计原则很硬核：发现者与验证者永远不是同一个 Agent；严重程度只看影响、不看偏离清单；单次运行大约只能找到多次运行总量的一半，多跑才有覆盖。2026 年 6 月建仓，MIT 开源，只有 14 次提交——一个小而精的技能定义。

💡 点评：与 codex-security 同日上榜不是巧合，安全审计正在变成 Agent Skills 最先被大厂验证的垂直场景；“对抗式验证”这条原则，值得所有 Agent 工作流借鉴。
