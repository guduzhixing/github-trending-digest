elementalsouls/Claude-BugHunter

把 Claude Code 变成有纪律的漏洞赏金猎手与外部红队操作员。作者是安全研究员 Sachin Sharma，仓库 2026 年 5 月创建、MIT 开源，内含 82 个技能、15 个斜杠命令，方法论来自 681 份公开披露的 HackerOne 报告（433 份逐条引用），覆盖 24 类核心漏洞：58 个 hunt 技能分管 XSS、SQLi、SSRF、IDOR、SSTI 等 Web 漏洞类，另有企业身份与基础设施攻击矩阵、侦察与报告技能。工作流是侦察、建图排序、狩猎、验证、报告五步，范围检查写进代码：只做互联网可达的外部攻击面，内网 AD、后渗透、C2、免杀明确排除，每条发现须过七问验证门才写报告。支持 Claude Code 插件安装，技能本身兼容 OpenCode、Codex、Antigravity 等 Agent Skills 标准格式。

HKUDS/CLI-Anything

港大 HKUDS 数据智能实验室的作品，论点很直接：今天的软件服务人类，明天的用户是 Agent；别再教 Agent 截图点按钮，直接给软件生成命令行。七阶段流水线（HARNESS.md）读任意软件源码、把 GUI 操作映射到底层 API，生成基于 Click 的 CLI：结构化 JSON 输出、REPL、撤销/重做，并附测试与文档；生成的 CLI 调用真实软件后端——LibreOffice 出真 PDF、Blender 渲真 3D 场景，不是重实现。配套 CLI-Hub（clianything.cc）是注册表加包管理器，约百个 CLI、35 个品类，已覆盖 GIMP、Blender、Inkscape、LibreOffice、OBS、Zotero、FreeCAD、QGIS 等，仓库自称 2,461 个测试全过。同实验室还出过 RAG-Anything，6 月有 arXiv 技术报告。

obra/superpowers

GoogleChrome/modern-web-guidance-src

Chrome、Edge、Firefox 与 MDN 四方联合维护的官方项目，解决一个具体毛病：LLM 训练数据里遗留代码太多，编码 Agent 写前端总默认用老套路。做法不是改模型，而是在 Agent 干活时把专家审定的现代 Web 指南喂进上下文：CLI 提供 search、retrieve、legacy-scan 三个命令，可检索指南、按 ID 取回单条（如 animate-to-from-top-layer），或扫描代码库找 legacy 模式。内容覆盖 250 个现代 Web 特性（CSS 与布局 140、JS 与 API 74、HTML 与 DOM 36）与 203 个真实开发场景，分属用户体验、CSS 布局、性能、表单与 UI、无障碍、内置 AI 六大学科，附 Baseline 兼容性标注。2026 年 5 月 Google I/O 首次发布，11 月 10 日刚发 v1.0.0。本仓库是作者与评测用的源码库，正式发布的技能在同名 release 仓库与 npm 包。

cloudflare/security-audit-skill

Cloudflare 开源的编码 Agent 安全审计技能，MIT 协议。它不是扫描器，而是一套指令集：把审计拆成六个阶段，由相互隔离的子 Agent 分工——侦察建架构图与覆盖台账、猎手按覆盖面找漏洞、对抗验证者独立复核发现，全程用覆盖台账（coverage-ledger.json）与结构化 findings 做确定性追踪，另附两个零依赖 Node 校验器。项目自述是 Cloudflare 内部漏洞发现流水线的单仓起点：据 Cloudflare 博客，该流水线处理了 128 个仓库，20,799 条原始候选压缩为 7,245 条可行动发现。需要支持并行子 Agent 的编码工具（Claude Code、Cursor、OpenCode、Codex 等）与 Node.js，审计只读代码、不碰线上系统。
