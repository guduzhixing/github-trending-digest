meta/astryx

设计系统Meta 官方Agent 就绪MIT
本周新增 13,660 星，总星数 28,142，Fork 2,194；周榜第一

Meta 内部打磨八年的设计系统开源版，在公司内是规模最大、使用最广的一套，支撑 13,000 多个应用。如今以 Beta 状态开源：150 多个无障碍组件、品牌级主题、深色模式、开箱即用的模板与 CLI，基于 React 19 与 StyleX。与一般组件库的区别有三点：内部结构开放（可用 swizzle 把组件源码整个导出到自己项目里改）、不锁定样式方案（用 Tailwind、CSS Modules 或原生 CSS 覆盖都行）、主题就是一组 CSS 变量覆盖。最关键的是“为人和 Agent 一起设计”：API、文档与 CLI 按同一套约定走，人和 AI 助手用同一份参考。2026 年 1 月建仓，已有 7,885 次提交、52 个版本。

💡 点评：Meta 把压箱底的设计系统拿出来，押注的是“Agent 也会写界面”的未来；设计系统正在从“给人用的组件库”变成“给人机协作的共同语言”。周榜第一实至名归。

JuliusBrussee/caveman

今日新增 227 星，总星数 120,060，Fork 7,002；日榜第十，总星数全榜居前

“少说废话”的省 token 工具：让 Agent 用极简的“穴居人”风格回答（先给结论、一句一个意思、代码与数字原样不动），并在 Agent 读取日志、JSON、CSV、测试输出前先压缩。项目方自测：整个会话输入 token 减少 33.2%，新推出的 Auto 模式（按任务难度自动选模型与 effort）称比 Opus 5.5 高 effort 便宜 54% 且得分相当；另有 Blocks（复用 Agent 写过的脚本）、Browse（压缩网页）等六块“石头”。曾被 Adobe Research 的论文引用、JetBrains 做过 86 个真实任务的 A/B 测试。最新动向是推出免费的 Caveman Code 编码 Agent。2026 年 4 月建仓，已有 2,042 次提交、56 个版本。

💡 点评：从一句玩笑长成 12 万星的省钱工具，caveman 抓住了 Agent 时代最实在的痛点——token 就是钱；不过 65%、54% 这类数字均为项目方自测，实际省多少要看自己的任务类型，别当成承诺。
