addyosmani/agent-skills

Agent Skills工程方法论全生命周期MIT
今日新增 816 星，总星数 116,660，Fork 12,209；日榜第三

Chrome 团队 Addy Osmani 的生产级工程技能库，把资深工程师的工作方式打包成 25 个技能，覆盖从定义、规划、构建、验证、评审到发布的完整生命周期。9 条斜杠命令对应开发流程：/spec 先写需求、/plan 拆任务、/build 增量实现、/test 测试即证明、/review 合并前质检、/ship 上线，技能也会按当前工作自动触发。安装只需 npx skills add addyosmani/agent-skills，可进 70 多种 Agent（Claude Code、Cursor、Codex、Antigravity CLI 等）。2026 年 2 月建仓，MIT 开源，已有 807 次提交、17 个版本。

💡 点评：Skills 热潮里最“工程化”的一支——它不教 Agent 写更多代码，教的是“先想清楚再写”；当所有人都在拼模型能力时，这类流程资产正在成为真正的护城河。

GoogleChrome/modern-web-guidance-src

Agent SkillsWeb 开发指南Chrome 官方Apache-2.0
今日新增 739 星，总星数 2,894，Fork 196；较昨日 159 星涨近 5 倍

Google Chrome 团队的现代 Web 开发指南源码库，由 Chrome、Edge、Firefox 与 MDN 团队共同维护，目标是让编码 Agent 不再默认写老模式。内含 250 个现代 Web 特性指南，覆盖 CSS 布局（容器查询、subgrid、oklch）、原生表单与弹窗、性能与无障碍、内置 AI 等：npx modern-web-guidance@latest install 一键装进 Agent，另有 search、retrieve 与 legacy-scan（扫描代码库里的 legacy 模式并建议现代化）命令。指南按 token 效率剪裁，并配有 eval 仪表盘验证效果。2026 年 1 月建仓，Apache-2.0 开源，已有 1,591 次提交。

💡 点评：模型训练数据里 legacy 代码太多，Agent 写前端总带着“旧味”——Chrome 直接把官方最佳实践做成技能喂给 Agent，这是平台方纠正模型行为最直接的一招。

CopilotKit/OpenBot

AI 同事AG-UI自托管MIT
今日新增 298 星，总星数 11,593，Fork 1,434；日榜第十一

CopilotKit 的开源 AI 同事工作台：每个 Bot 各自拥有一台电脑——浏览器、文件与工具齐全，每个动作事前定好、事后留痕，发送前需经批准。基于 AG-UI 协议，可接入 Claude Agent SDK、LangGraph、Google ADK、CrewAI 等 20 多种 Agent 框架与执行平台，模型任选 OpenAI、Claude、Gemini 或本地开源模型；前端覆盖 Mac、Windows、Web、iOS、Android、Slack 与 Teams，也可 Helm 部署到自有 Kubernetes。应用模板 MIT 开源，但 CopilotKit Intelligence（持久对话、记忆与治理服务）需单独授权，个人本地使用有免费许可。2026 年 8 月建仓，已有 1,105 次提交、37 个版本。

💡 点评：与 OpenMausBot 同题不同解——OpenBot 更像“企业级工作台”，治理、审计与部署是主菜；Agent 从聊天框走向工位，合规与可审计正在变成标配。

milind-soni/OpenMausBot

Grok Bot 替代个人 Agent 团队本地优先Apache-2.0
周增 9,104 星，总星数 21,708，Fork 3,019；本周增量第二

开源的 Grok Bot 替代品，把“AI 当作聊天应用”的形态彻底开源化：侧边栏里每个 Bot 都是一个真实 Agent，底层跑你本机已装的 Claude、Codex 或 Grok CLI，用你自己的登录与订阅，不经过中间代理。每个 Bot 有自己的性格、模型、云端电脑与已接应用（通过 Composio 接 Gmail、Slack、GitHub 等 500 多个应用），危险操作以卡片形式请你批准；房间设为 Auto 时，Jev 决策模型在几百毫秒内判断该由哪个 Bot 回复；整个团队还能导出成一个 Markdown 文件分享。本地优先，记录与密钥只存在 ~/.openmausbot。2026 年 8 月建仓，Apache-2.0 开源，已有 10,256 次提交、111 个版本。

💡 点评：四款闭源个人 Agent（Grok Bot、Muse、dots、cue）七周内相继出世，OpenMausBot 是开源世界最完整的回应——“一支队伍”正在取代“一个助手”成为个人 Agent 的新形态。

Alishahryar1/free-claude-code

免费 Token模型路由多 HarnessAGPL-3.0
今日新增 415 星，总星数 69,282，Fork 10,757；日榜第十二

把 12 种编码 Harness（Claude Code、Codex、Pi、OpenCode、Antigravity CLI、VS Code 等）接到 61 个模型供应商上的本地代理：装好后 fcc-claude、fcc-codex、fcc-pi 即可开跑，模型在 Admin UI 里切换，失败自动重试、限流与多密钥 fallback。卖点是“免费”：项目称各供应商免费额度合计每月 13 亿以上 token（免费额度由各供应商控制、可能变化），并有 RTK 与 Headroom 两项 token 优化，号称最高可省 90% 用量；另支持终端、桌面 App、手机（Discord/Telegram）与浏览器内原生会话。2026 年 1 月建仓，AGPL-3.0 开源，已有 1,250 次提交、118 个版本。

💡 点评：模型越来越贵、免费额度越来越散，路由层就成了新的省钱入口；但“免费”二字全系于各家供应商的脸色，适合当作主力之外的第二通道。
