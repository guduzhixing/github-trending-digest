milind-soni/OpenMausBot

TypeScriptGrok Bot 开源替代多 Agent 聊天Jev 决策路由
今日新增 1,955 星，总星数 16,963，Fork 2,401；日榜第三，周增 7,077 星

开源的 Grok Bot 替代品，思路是把“一队 AI 机器人装进聊天 App”：侧边栏里的每个机器人都是真实 Agent（本机跑 Claude、Codex 或 Grok CLI），自带人设、模型、自己的云端电脑与已连接应用，用你自己的订阅、不经过中间代理。本地优先：记录、密钥与事件都存在本机 ~/.openmausbot。每个机器人可配云端 Linux 桌面、本地隔离虚拟机或经明确授权的本机，Shell 命令与文件编辑会以审批卡片先问过你；频道机制把工作、个人与各项目分开；消息该由哪个机器人回，由 Jev 决策模型在数百毫秒内路由；整支团队能从一个 Markdown 文件一键装入，也能把整个部门导出分享。仓库 2026 年 8 月 11 日建仓，已有 8,704 次提交、105 个 Release，Apache 2.0 开源。

💡 点评：Grok Bot、Muse、dots、Cue 四款闭源个人 Agent 七周内密集发布之后，开源世界给出的回应不是再造一个助手，而是一整个“机器人通讯录”——模型、电脑与数据都留在自己手里；Jev 决策模型在这里是真实落地的路由环节，值得留意。

sherlock-project/sherlock

PythonOSINT用户名检索安全工具
今日新增 1,766 星，总星数 100,430，Fork 11,863；日榜第四，总星数刚破 10 万

开源社区的老牌 OSINT 工具，解决的问题很具体：只知道一个用户名时，快速查出它在哪些社交网络注册过账号，拼出一幅公开账号版图。Python 写成，用法就是命令行里给一个用户名、等它逐站比对返回结果。适用场景是安全研究、招聘背调与记者核查一类的公开信息核验，使用时须遵守各平台规则与当地法律。它在 Agent 时代翻红并不意外：Agent 满世界替人办事之前，先要确认对面是谁。

💡 点评：工具本身没有新功能，火的是需求——身份核查从安全圈的手艺活，正在变成 Agent 工作流的前置步骤。

thedotmack/claude-mem

TypeScriptAgent 记忆跨会话上下文本地优先
本周新增 7,482 星，总星数 114,471，Fork 9,927；周榜首位，月增 17,493 星

解决“Agent 每换一次会话就失忆”：用钩子把 Agent 的每一步工具调用交给本地小 worker，第二位“观察者 Agent”边干活边记笔记，会话结束写摘要；下次开会话先给一份分层索引，需要时再展开细节，不用把历史全塞进上下文。支持 Claude Code、Codex、Cursor、OpenCode 等十余种 Agent；记忆存在本机 ~/.claude-mem（SQLite + Chroma 向量库），云同步需主动开启，<private> 标签包裹的内容不会被存下来。仓库 2025 年 8 月 31 日建仓，4,023 次提交，Apache 2.0 开源。

💡 点评：Skills 解决“会不会干活”，claude-mem 解决“记不记得干过”——Agent 从一次性工具变成长期协作者，记忆层是绕不过去的一环；周榜首位说明开发者已经在为这件事投票。

D4Vinci/Scrapling

Python爬虫框架反爬MCP
本周新增 8,712 星，总星数 99,320，Fork 10,397；周增第二，距 10 万星只差 680

Python 爬虫框架，把“能抓、能扛、能交给 Agent”做进同一个库：Fetcher 做快速请求（可模拟浏览器 TLS 指纹、支持 HTTP/3），StealthyFetcher 处理 JavaScript 渲染与 Cloudflare Turnstile 之类的反爬，Spider 式并发爬取带暂停/恢复、代理轮换、自动限流与 robots.txt 遵守；解析支持 CSS、XPath 与自适应元素追踪，导出 JSON/CSV/XML；还带 MCP 服务器与 Agent Skill，AI Agent 可以直接调用它抓取。仓库 2024 年 10 月 13 日建仓，1,823 次提交，BSD-3 开源。

💡 点评：爬虫框架的竞争点已经从“能不能抓”移到“Agent 能不能直接用”——MCP 与 Skill 成了新标配；按本周增速，破 10 万星就在这几天。
