morluto/rea

TypeScript周榜第1MIT周新增 201,065 星总星 336,603
史上罕见的星数曲线：4 月建仓默默无闻，7 月 Show HN 只拿 3 分；10 月 8 日 v6.0 发布后垂直起飞，10 月 6 日不到 1 万星 → 10 月 14 日约 23 万星，单日曾涨超 3 万星。

REA（Reverse Engineer Anything）是一个 MCP server + CLI（npm 包 rea-agents），把逆向工程的老牌工具——Ghidra 无头反汇编、Hopper、IDA Pro（经 MCP 桥接）——接进 Claude Code、Cursor、Codex 等 coding agent。用法是一个三步循环：反编译拿到可读伪代码与命名线索、追踪执行解释某个功能如何工作、再在自己的技术栈里重建。v6.0 新增的以太坊 EVM 字节码离线检查、pwntools/pwndbg 崩溃分析、Windows x86 支持是引爆点。作者明确其边界：不恢复原始源码、不整站克隆，结论附证据与 caveat，且分析全在用户本机运行。顺带：周榜里 NSA 的 Ghidra 本周也涨了 7,152 星，显然是蹭了这波东风。适合安全研究、恶意软件分析、闭源 SDK 兼容性开发。

💡 判断：agent 的"眼睛"第一次正式伸进二进制世界；注意已有仿冒仓库挂木马，只认 npx rea-agents setup 和 morluto 本人仓库。

debpalash/VoiceStudio

Python月榜第2AGPL-3.0月新增 44,161 星总星 77,476
本月热榜前三常客。原名 OmniVoice-Studio，自称"完全本地、开源的 ElevenLabs 替代"，646 种语言的声音克隆、声音设计、视频配音、听写、转写、有声书制作全在本机完成。

默认引擎是 k2-fsa 的 OmniVoice，可在模型管理器里切换其他引擎。形态上是 Electron 桌面应用（Clone / Dub / Design / Models 四个工作区）+ 本地 OpenAI 兼容 API + MCP server：agent 可以直接调用它做旁白生成或音频转写，数据不出本机——这是它区别于一般桌面 TTS 工具、被开发者社区追捧的关键。隐私口径写得清楚：本地工作流跑在用户硬件上，远程服务可选，数据分析需用户同意。两处提醒：AGPL-3.0 意味着商用产品内嵌/云端提供要过法务；"ElevenLabs 平替"是项目自称，尚无公开的 MOS 等客观音质评测，646 语言的实际质量落差未知。适合播客/短视频配音、需要离线语音能力的多语言产品、以及想把语音塞进 agent 工作流的人。

💡 判断：语音 AI 正在复刻代码 agent 的路径——从云端订阅走向"本地引擎 + agent 可调用"。

anomalyco/opencode

TypeScript日榜第2MIT日新增 1,311 星总星 217,788
刚发布 2.0，21.7 万星稳居 GitHub 上 star 最多的开源 coding agent。注意仓库已从 sst/opencode 迁至 anomalyco/opencode（团队由 SST 更名为 Anomaly Innovations），旧链接会自动跳转。

OpenCode 是跑在用户本机、模型无关的 agentic coding 工具：终端 TUI、桌面应用、浏览器、IDE 插件四种形态，一个后台服务驱动全部前端；经 Models.dev 接入 75+ 模型供应商，也可用已有的 GitHub Copilot / ChatGPT 订阅登录。Plan（只读分析）→ Build（动手改）→ Verify（跑测试）是它的标准工作流。2.0 的新东西：subagent 可后台运行、Code Mode 把 MCP 工具链成一条脚本执行。商业模式是"agent 免费、模型自费"：自带少量免费模型，另有 Go（$10/月）与 Zen（按量付费）两种官方模型通道。适合不想被单一模型锁定的开发者、预算敏感的团队，以及偏好终端工作流的人。

💡 判断：2.0 把"多前端 + 后台服务"做成标配，coding agent 正在从 CLI 玩具变成正经的桌面级生产力软件。

stablyai/orca

TypeScript日榜第6MIT日新增 1,590 星总星 98,255
3 月创建、已发 973 个 release，"舰队管理"类工具里星数最高。解决的问题很具体：当你的工作变成"同时指挥多个 agent"时，逐个终端切来切去就是瓶颈。

Orca 是一个开源桌面应用（另有手机 companion App），把 Codex、Claude Code、OpenCode、Pi 等任意终端 agent 并排跑起来，每个 agent 独占一个隔离的 git worktree——同一个任务可以 fan-out 给五个 agent 各做一版，最后比 diff、合并优胜者。亮点功能：手机远程查看 agent 进度并追问、SSH 连远程大机器跑 worktree、在 Chromium 真窗口里点任意 UI 元素把 HTML/CSS/截图直接塞进 agent 的 prompt、在 diff 行上批注回传给 agent。应用本身免费开源，但 agent 的订阅/API 费用自理，并行三个 agent 意味着三倍的 quota 消耗。适合重度依赖 coding agent、经常需要"多方案赛马"的开发者。

💡 判断：agent 普及之后，"管 agent 的工具"成了新热土；Orca 是这个品类目前完成度最高的一个。
