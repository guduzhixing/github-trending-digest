NVIDIA/auto-ontology

PythonAgent 语义层知识图谱NL-to-SQL
今日新增 2,050 星，总星数 4,938，Fork 395；日榜第一

NVIDIA 官方出品的语义层框架：从企业数据库元数据自动生成“本体”——业务术语、指标口径、表间关系构成的知识图谱，再经 MCP、CLI 或 API 供 Agent 调用。核心卖点是“可验证的问答”：Agent 回答业务问题时，先把“收入”“客户”这类词解析到本体中经人工认证的定义上，再生成 SQL，答案附带 SQL 与推导步骤；答不出来的问题会明确说数据不支持，而不是编一个数。推理默认走 NVIDIA NIM 模型，适合把 Agent 接入企业内部数据、被“数字对不上”折磨的数据团队关注。

💡 点评：Agent 从“能聊天”走向“能算账”，最大的拦路虎就是口径不一致；NVIDIA 这一步是把语义层从各家私有实现里抽出来做成开源基础设施。

FareedKhan-dev/kimi-k3-in-c

C本地推理MoE零依赖
今日新增 351 星，总星数 10,282，Fork 1,628；日榜第十一

把 2.78 万亿参数的 Kimi K3 搬到单颗 CPU 上跑、内存占用只要 8.24GB 的纯 C99 推理引擎：无 BLAS、无框架、无 GPU 依赖。关键是 MoE 红利叠加四层压缩：专家权重已是半字节量化，每 token 只激活 896 个专家中的 16 个；注意力改用不随序列增长的 KDA 与单隐向量 MLA；主干 93 层打包成“每层只读一次”的流式结构，专家按需从 1.56TB 检查点经 LRU 缓存加载。代价也写在明处：1.56TB 检查点与磁盘流式加载，决定了它更像研究向概念验证，而非日常聊天后端。

💡 点评：继昨日纯 C 跑 744B 模型之后，本地推理的“极限挑战”赛道又添一员；看热闹要看门道——它证明的是 MoE 时代“参数量≠内存量”，不是“人人都能在笔记本上跑 K3”。

max-sixty/worktrunk

RustGit 工作树并行 Agent开发者工具
今日新增 531 星，总星数 11,014，Fork 411；日榜第二、周榜第七（周增 1,261 星）

为并行 Agent 工作流而生的 Git 工作树管理 CLI，作者自称已是“最受欢迎的工作树管理器”。痛点很具体：原生 git worktree 建一个工作树要把分支名敲三遍；而 Agent 时代一个人同时管 5–10 个 Agent，每个各占一个工作目录，手工管理很快失控。Worktrunk 把工作树当分支操作：wt switch feat 一条命令建分支、建工作树并切过去，wt switch -x claude feat 直接在新工作树里启动 Agent，另有钩子、合并流程、交互式选择器、共享构建缓存等周边。适合已用多 Agent 并行开发、被工作树目录淹没的开发者。

💡 点评：Agent 数量上去之后，瓶颈先出现在最不起眼的地方——目录管理；这类“小工具、大刚需”正是它登榜的原因。

mattpocock/skills

ShellAgent Skills工程实践提示词
今日新增 1,379 星，总星数 313,293，Fork 26,280；日榜第三

出自 Matt Pocock 个人 .agents 目录的 Agent Skills 合集，副标题直言“给真正的工程师的 Skills”。它不是花哨框架，而是作者日常沉淀的技能包：让编码 Agent 按既定套路做事，而不是每次自由发挥。总星数突破 31 万，是今日日榜体量最大的仓库——说明“Skills”已从潮流词变成多数 Agent 用户的默认装备：与其争论哪个 Agent 更强，不如先把好实践写成可复用的技能文件，适合在 Claude Code、Cursor 里配工作流的工程师直接抄作业。

💡 点评：榜单这周被各类 Skills 刷屏不是偶然——Agent 能力的上限，正在从模型参数转向“你给它的工作手册写得有多好”。

harry0703/MoneyPrinterTurbo

PythonAI 短视频自动化工作流AIGC
今日新增 617 星，总星数 138,940，Fork 22,169；日榜第九

国产开源的 AI 短视频“一键生成”工具：输入一个主题或关键词，就自动走完选题、文案、大模型配音、素材匹配、剪辑合成的整条流水线，输出高清短视频。它火的原因不难理解：短视频仍是流量最大的内容形态，而这条工具链把“做一条视频”从半天手工活压缩成一次自动任务。总星数近 14 万、Fork 超 2.2 万，说明它早已不是昙花一现的 Demo，而是被大量个人创作者与小团队实际用起来的生产工具。适合想批量做短视频内容、但不想逐条剪片的创作者与运营者评估。

💡 点评：AIGC 工具的竞争已经从“能不能生成”转到“能不能端到端交付成品”；MoneyPrinterTurbo 正是后一种路线的代表。
