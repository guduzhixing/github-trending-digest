日新增 2,716 星 · 总星数 42,114 · 日榜第 1
💡 Cloudflare 开源的 agent skill，把 coding agent 变成安全审计员：六个阶段——架构侦察、覆盖率驱动猎杀、候选验证、结构化输出、记录复核、报告生成，核心设计是"发现漏洞的 agent 永远不许验证自己的发现"，每个候选漏洞都要交到一个从零开始、专职证伪的验证 agent 手里。发现落盘为机器可读的 findings.json，三档结论：confirmed / needs_validation / rejected。MIT 协议，本质是 Cloudflare 内部漏洞发现流水线的"种子版本"。适合有安全基线需求的开发团队做定期深度审计或发版前评审。诚实点说：官方承认单次运行只能找到约一半漏洞，token 消耗大，需要支持并行子 agent 的模型，且跑目标代码前必须配无网沙盒。
