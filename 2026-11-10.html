morluto/rea

TypeScript逆向工程MCPAgent 工具
月新增 413,718 星，总星数 446,926，Fork 110,239；月榜断层第一，月增量接近总星数

REA（Reverse Engineer Anything）是一个 MCP 服务器加命令行工具，让 AI 编码 Agent 直接调用真正的逆向工程工具：Ghidra、IDA、Hopper 做原生二进制反编译，另有内置读取器处理 JavaScript、.NET、Android APK、网站与固件。用法是一行命令 npx rea-agents setup，把它注册进 Claude Code、Codex、Cursor、Gemini CLI 等支持本地 MCP 的 Agent；之后向 Agent 提问“这个 App 的某个功能怎么实现的”，Agent 自己决定查什么，把伪代码、汇编、字符串与引用连同证据一起交回来，分析全在本地跑。仓库 2026 年 4 月建仓、MIT 开源，最新版 rea-agents 6.8.0（10 月 25 日）。爆发点在 10 月中旬：第三方统计显示 10 月 13 日约 13 万星、10 月 28 日已近 40 万星，一个月涨 40 万星是 GitHub 罕见量级。适用人群是安全研究员、做兼容性与软件考古的开发者，以及想搞懂竞品某个功能怎么实现的工程师。提醒两点：README 明确只限合法用途（自己拥有或获授权分析的软件），且市面已有仿冒仓库，只认 morluto/rea、rea.tools 与 npm 上的 rea-agents。

💡 点评：Agent 的手已经伸进二进制世界——以前逆向是少数人的手艺，现在变成向 Agent 提一个问题的事；但能力越强，合法使用的边界越要先讲清楚。

vercel-labs/agent-desktop

RustComputer Use无障碍树Agent 工具
本周新增 12,120 星，总星数 20,441，Fork 1,514；周榜第二，今日新增 916 星

Vercel Labs 的 computer use CLI：让编码 Agent 操作真实桌面应用，办法不是截屏猜像素，而是读操作系统无障碍树——屏幕阅读器用的那套结构，每个按钮、输入框、菜单都有角色与标签。快照命令返回一份 JSON，每个可操作元素带一个稳定引用，Agent 按引用点按、输入、滚动，再读一遍界面验证结果、循环执行。60 个命令覆盖观察、操作、键盘鼠标、窗口管理、剪贴板与会话；工具本身不含模型，推理全在调用它的 Agent 里。支持 macOS、Windows、Linux，1.0 版 10 月 27 日发布，Apache-2.0 开源，npm install -g agent-desktop 即装。它是 agent-browser 的姊妹项目——浏览器那套思路搬到了整个桌面。注意：macOS 需授予无障碍权限；快照与剪贴板可能含私人内容，别进公开日志。

💡 点评：Agent 的操作面从终端、浏览器扩到了整个桌面；无障碍树这条路比截屏更稳、更省 token，computer use 正在从演示走向可用的工具。

💡 点评：设计系统也开始按“Agent 能读、能改、能搭”来设计，UI 库的竞争维度多了一条；Meta 把内部最大设计系统开源，是在抢 Agent 时代前端基建的话语权。

NVIDIA/auto-ontology

Python语义层NL-to-SQLAgent 推理
本周新增 10,159 星，总星数 11,008，Fork 898；周榜首位，本周新增占总星数九成以上

NVIDIA 开源的 Python 框架，给企业数据建一层“语义推理层”：从数据库元数据自动生成本体（术语、关系、SQL 属性），再由人认证，最后 Agent 通过 MCP、CLI 或 API 用它回答自然语言问题、生成 SQL。解决的核心痛点是 Agent 查数“快但不一定对”——各系统里指标口径不一致时，先统一定义再查数；答案附带 SQL 与推导步骤、可溯源，数据里答不了的问题会先说“没有”而不是编一个。技术栈为 FastAPI + LangChain 后端、Next.js 前端、Postgres + pgvector 存本体，推理默认走 NVIDIA NIM（Nemotron 系列模型），支持 Databricks、Postgres、Snowflake、DuckDB。11 月 4 日左右开源，首日约 2,000 星，Hacker News 讨论帖约 291 分、139 条评论；Apache 2.0 开源，但目前不接受外部贡献。

💡 点评：Skills 管“会干活”、记忆层管“记得住”，auto-ontology 补的是“算得对”——Agent 从写代码走向查数、做分析时，口径统一的语义层是绕不过去的一环；NVIDIA 这次直接把自家 NIM 模型与开源框架绑在一起推。
