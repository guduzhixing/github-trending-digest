obra/superpowers

Agent 方法论Skills 框架TDDMIT
今日新增 1,917 星，总星数 319,317，Fork 28,477；日榜新增星数第一

Superpowers 不是又一个技能合集，而是一套完整的软件开发方法论：Agent 动手写代码之前先做头脑风暴、把需求聊成可读的设计文档，设计通过后拆成 2–5 分钟能做完的小任务，再由子 Agent 逐个执行、每步复核，全程强制红绿 TDD、YAGNI 与 DRY。它由 obra 维护，2025 年 10 月创建至今已有 687 次提交，技能按需自动触发，不用记命令。安装面极广：Claude Code 官方插件市场、Antigravity、Codex、Cursor、Gemini CLI、Pi、Qwen Code、Muse 等十余个平台都有接入方式。

💡 点评：技能潮的上半场是“攒技能”，下半场是“定章法”——当人人都有几十个技能时，真正稀缺的是让 Agent 几小时不跑偏的工作流。Superpowers 总星数已超 31 万，是这波热潮里体量最大的方法论项目，值得每个重度用 Agent 写代码的人装上试一次。

dream-num/univer

Office SDK表格文档AI AgentApache-2.0
今日新增 1,774 星，总星数 28,893，Fork 2,616；连续第三天日榜第一（前两日分别为 988、1,828 星）

DreamNum 出品的开源 Office SDK：把真正能算公式的表格、文档、幻灯片嵌进自己的产品，而不是再套一层商业表格控件。核心是微内核加插件架构、Canvas 渲染与自研公式引擎，同一套 API 在浏览器与 Node.js 无头运行时通用。9 月 24 日发布 1.0 后团队把定位改成“The Office Harness for AI Agents”：Agent 通过结构化 API 读写表格文档，在隔离的 worktree 草稿里改、由人审阅合并，还能截图校验结果。注意开源核心只含基础编辑与计算，实时协作、导入导出 xlsx、图表与透视表属于付费的 Univer Pro 层。

💡 点评：三天 988 → 1,828 → 1,774 星，曲线稳在高位，说明“给 Agent 配办公套件”不是一日热度。Agent 开始替人做表，Office SDK 正在变成 Agent 基建里的一块标准件。

安全技能Bug Bounty红队MIT
今日新增 1,005 星，总星数 9,248，Fork 1,357；本周新增 2,508 星

面向漏洞挖掘与外部红队的 Claude Code 技能包，由安全研究员 Sachin Sharma 打造：83 个技能、15 条斜杠命令，58 个 hunt 类技能源自 681 份已公开的 HackerOne 报告模式，覆盖 24 类核心漏洞；另有企业身份与基础设施攻击矩阵（M365/Entra、Okta、vCenter、SSL-VPN 设备、云 IAM）。工作流分侦察、建图排序、挖掘、验证、报告六个阶段，提交前过一道“七问门禁”，并明确只用于自有资产或已授权评估目标，内网 AD 攻击、C2 与后渗透被明确划出范围。同一套 SKILL.md 可装进 Claude Code、OpenCode、Codex CLI、Hermes 与 Antigravity。

💡 点评：技能潮从写代码扩散到安全攻防，方法论也在变专业——不是堆 payload，而是把公开报告沉淀成可复用的挖掘模式。安全从业者值得关注，但要先把授权边界这条线划清楚。

alibaba/open-code-review

代码评审LLM Agent阿里巴巴混合架构
今日新增 763 星，总星数 53,715，Fork 4,429；本周新增 3,675 星，连续四日高位

阿里巴巴开源的代码评审工具，主打“确定性流水线 + LLM Agent”的混合架构：先用确定性规则做精确的行级检查，再由 Agent 做语义判断，内置多语言规则集，覆盖空指针、线程安全、XSS、SQL 注入等常见问题，兼容 OpenAI 与 Anthropic 的模型接口。卖点是“在阿里规模下经过实战检验”——大厂内部评审工具开源，天然自带可信度背书。

💡 点评：代码评审是 Agent 落地最先被验证的场景之一；连续四日每天七八百星，热度没有一日游。想在 CI 里加一层 AI 评审的团队可以直接拿来试。

多 Agent论文写作Google ResearchApache-2.0
今日新增 1,072 星，总星数 2,968，Fork 411；较昨日 313 星增长两倍多

Google Cloud AI Research 出品的多 Agent 论文写作框架：把未经整理的写作素材（想法、实验日志）变成可投稿的 LaTeX 稿件。五个专业 Agent 分工协作——大纲、文献综述、章节写作、内容打磨、绘图，自动检索并整合相关文献、按目标会议模板出稿，还能用代码生成图表。支持 Gemini 与 OpenAI 模型，配有 Streamlit 交互演示。仓库声明并非谷歌官方支持产品，论文配套数据集尚未随代码发布。

💡 点评：从昨日 313 星到今日 1,072 星，涨幅本身就是信号——学术写作也开始上 Agent 流水线。写论文的研究者可以拿来试，但别指望它替你做实验与判断，成稿质量仍需人工把关。
