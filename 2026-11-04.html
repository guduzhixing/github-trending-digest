vercel-labs/agent-desktop

Rust桌面 Computer Use无障碍树跨 Agent
今日新增 3,791 星，总星数 12,692，Fork 875；日榜第二、单日涨幅第一

昨天刚登顶的 Vercel 桌面操作 CLI，今天以单日最大涨幅续写热度：它本身不内置模型，而是让 Claude Code、Codex、Cursor 这类编码 Agent 通过操作系统的无障碍树读取并操作 macOS、Windows、Linux 上的原生桌面应用。Agent 拿到带引用的 JSON 界面快照，按引用点击、输入、滚动，再读一遍界面确认结果，默认不抢鼠标、不夺焦点，多个 Agent 可以并行。短短两天总星数从 9,614 涨到 12,692，说明“Agent 走出终端、接管整个桌面”这个方向正在从概念验证变成多数人愿意动手试的工具。

💡 点评：做桌面自动化或 Agent 工具链的人值得第一时间试；但要先接受它的硬边界——不暴露无障碍树的应用，它够不着。

TypeScriptAgent 记忆会话上下文跨工具
今日新增 1,139 星，总星数 111,878，Fork 9,736；日榜第一，周榜新增 7,995 星，月榜新增 16,740 星

连续多日霸榜的 Agent 长期记忆层：把每次会话中 Agent 的工具调用、决策与结果记录下来，用 AI 压缩成结构化记忆，在未来会话中按需注入，覆盖 Claude Code、Codex、Gemini、Copilot、OpenCode 等工具。日、周、月三榜同时居前，总星数突破 11 万后单日仍涨过千星，说明它已从尝鲜工具变成不少人工作流里的默认配置。逻辑很直白：Agent 开始承担多天、跨项目的连续工作时，再大的上下文窗口也装不下全部历史，外部记忆就从加分项变成了刚需。

💡 点评：记忆正在成为 Agent 基础设施的标配层；上车前先想清楚两道关：记什么、不记什么，以及旧记忆出错时如何纠正。

从单次请求到全量爬取一站式包办的 Python 爬虫框架，今天以 1,658 星的单日增量回到日榜前排，总星数逼近 10 万。它把请求、解析、反爬对抗、并发调度这些爬虫工程里最磨人的部分收进同一套框架，目标是让“写个爬虫”不再从拼散件开始。在 Agent 需要自己上网找资料、做调研的今天，一个趁手的爬取层恰好是数据入口的刚需——这也是它在总星数已近 10 万的情况下仍能单日大涨的原因。

JustVugg/colibri

C本地推理MoE零依赖
今日新增 802 星，总星数 47,239，Fork 5,464；日榜第四

纯 C、零依赖的本地推理引擎，目标是把 744B 参数的 MoE 前沿模型搬上普通消费级机器：只把约 17B 参数的稠密部分（注意力、共享专家、词嵌入，int4 约 9.9GB）常驻内存，其余两万多个路由专家（约 370GB）按 token 需要从 NVMe 磁盘按需流式加载，辅以分层 LRU 缓存与推测解码。它证明的是可行性而非速度——作者自测的低配机冷启动只有 0.05–0.1 token/秒，离实时对话还很远；但对想在本地跑前沿大模型做研究的人，它把硬件门槛从“多卡机房”降到了“一台带大硬盘的电脑”。

💡 点评：本地大模型爱好者与推理引擎开发者必看；但先算好 370GB 磁盘与龟速出词的账，再决定要不要动手。

floci-io/floci

JavaAWS 本地模拟LocalStack 平替免费开源
今日新增 482 星，总星数 28,755，Fork 3,202；日榜第八

免费开源的本地 AWS 模拟器，定位直指 LocalStack 的平替：无需云账号、无需认证令牌、没有付费功能门，一条 docker compose up 就能在本机跑起 AWS 形态的服务，SDK、CLI、Terraform、CDK 指向 http://localhost:4566 即可沿用原有工作流。按项目 README 的说法，Lambda、RDS、ElastiCache、ECS、EC2 等重活不用浅层 mock，而是走真实 Docker 执行；另有 Azure、GCP、OCI 的同系列模拟器。它火的背景很现实：本地开发与 CI 本来就不该为“测一下云”付云账单、等云配额。

💡 点评：常年被云端测试环境拖慢的后端与 DevOps 团队值得一试；但迁移前先对照官方服务清单核对自己用到的服务覆盖度。
