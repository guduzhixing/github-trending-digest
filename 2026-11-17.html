dream-num/univer

Office SDK表格文档AI AgentApache-2.0
今日新增 1,828 星，总星数 27,768，Fork 2,524；连续第二天日榜第一（昨日 988 星）

DreamNum 出品的开源 Office SDK：把真正能算公式的表格、文档、幻灯片嵌进自己的产品，而不是再套一层商业表格控件。核心是微内核加插件架构、Canvas 渲染与自研公式引擎，同一套 API 在浏览器与 Node.js 无头运行时通用。9 月 24 日发布 1.0 后团队把定位改成“The Office Harness for AI Agents”：Agent 通过结构化 API 读写表格文档，在隔离的 worktree 草稿里改、由人审阅合并，还能截图校验结果。注意开源核心只含基础编辑与计算，实时协作、导入导出 xlsx、图表与透视表属于付费的 Univer Pro 层。

💡 点评：单日新增从 988 涨到 1,828，说明“给 Agent 配办公套件”不是一日热度；Agent 开始替人做表，Office SDK 正在变成 Agent 基建里的一块标准件。

ag-ui-protocol/ag-ui

Agent 协议前端交互1.0 已发布MIT
今日新增 791 星，总星数 18,948，Fork 1,963；日榜第二

AG-UI 是把 Agent 接进前端应用的开放协议，定位很清晰：MCP 给 Agent 接工具，A2A 让 Agent 之间协作，AG-UI 负责把 Agent 带到用户面前。Agent 不适合请求-响应模型——它要流式输出、中间调工具、更新共享状态、中途等人确认、派生子 Agent，AG-UI 用一条双向事件流把这些统一起来：Agent 发类型化事件，任何客户端都能渲染，同一 Agent 可以驱动 Web、移动端、终端或 Slack。1.0 版规范已冻结并有 JSON Schema 背书，TypeScript、Python、.NET 三个 SDK 由规范生成；LangChain、CrewAI、Google ADK、微软 Agent Framework、Mastra、Pydantic AI、LlamaIndex 等主流框架均已内置集成，CopilotKit 团队出品。

💡 点评：协议 1.0 冻结是生态成熟的信号——从“各家自己接线”到“按同一份规范接线”，Agent 前端这块终于有了标准答案。做 Agent 产品的团队值得把它放进技术选型清单。

NVIDIA/SkillEvaluator

技能评测Agent Skills三层框架Apache-2.0
今日新增 873 星，总星数 2,678，Fork 360；较昨日 122 星暴涨七倍

英伟达开源的 Agent 技能评测框架，回答技能潮里最缺的一问：这个 SKILL.md 到底有没有用。三层各司其职：Tier 1 静态质检（格式、密钥与 PII 扫描、隐藏 Unicode、脚本 lint，集成 SkillSpector 做安全扫描）；Tier 2 语义去重（技能之间是否重复）；Tier 3 实测（在沙箱里让 Agent 同一任务跑两次——装技能与不装——算出 Skill Lift 提升值）。配套论文称 947 组配对实测平均 Skill Lift 为 0.2134，72.8% 的技能确有正向提升；官方博客称 300 多个已验证技能平均正确率提升 41 分。标注为 Experimental（实验性，无 SLA），Tier 1 不用 API key 就能跑。

💡 点评：从昨日 122 星到今日 873 星，涨幅本身就是信号——技能从“人人都会写”走向“写完要测”，评测框架是生态成熟的标志。不过论文里的提升数字来自英伟达自家已验证技能目录，别直接当成自己技能的承诺；写技能、管技能库的团队可以先从 Tier 1 用起。

alibaba/open-code-review

代码评审LLM Agent阿里巴巴混合架构
今日新增 951 星，总星数 52,922，Fork 4,294；日榜第四，本周新增 3,056 星，连续三日高位

阿里巴巴开源的代码评审工具，主打“确定性流水线 + LLM Agent”的混合架构：先用确定性规则做精确的行级检查，再由 Agent 做语义判断，内置多语言规则集，覆盖空指针、线程安全、XSS、SQL 注入等常见问题，兼容 OpenAI 与 Anthropic 的模型接口。卖点是“在阿里规模下经过实战检验”——大厂内部评审工具开源，天然自带可信度背书。

💡 点评：代码评审是 Agent 落地最先被验证的场景之一；连续三日近千星，热度没有一日游。想在 CI 里加一层 AI 评审的团队可以直接拿来试。
